# Slurm 三节点 NIA_LS 实验

**目标：** server、node1、node2 每节点 180 个实例并发，每实例 1200 秒，统一结果目录和三张统计表。

**设计：** 一个 sbatch 作业申请三个节点，srun 每节点启动一个 Python worker，各自复用现有 run_batch 线程池。提交端只选择一次实例并保存全局序号；按序号轮转分片。分片目录独立写入，汇总时严格检查身份、指纹、重复和缺失，再恢复原全局 artifact 命名。根 manifest 记录总并发 540 与每节点并发 180。

**部署：** node1/node2 缺少系统 libz3.so.4 与 libgmpxx.so.4，因此冻结 native、其非 glibc 动态库、转换器 Python SDK 和 libz3.so、统计脚本及对手表到共享目录。每节点检查后执行。1200 秒是单例预算；Slurm 作业预算按批次数计算并留汇总余量。提交失败或节点失败保留不完整结果，不能显示为完整实验。
