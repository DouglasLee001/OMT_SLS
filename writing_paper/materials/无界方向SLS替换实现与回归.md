# 无界方向 SLS 替换：实现与回归

日期：2026-11-02。当前可执行文件：`z3-nia/build/z3`，SHA256 为 `c5307482fa39e0243bff1d4706789e36fb2321c67bc962c3b81eb2ef6e841f30`。

## 本轮实现

无界方向查询已移除 Z3 context、Z3 方向变量和 `solver.check()`，改用直接处理线性整数行的 GMP 局部搜索。有限最优证明等其他 Z3 通道保持原有职责；本轮替换只针对无界方向合成。

方向搜索仍由当前可行点出发，先选择覆盖子句的真文字，固定部分因子，使所选文字及目标精确仿射，再求永久保持文字且目标严格改善的整数方向。成功候选仍经原有 `verify()` 独立重读完整 native CNF 和多项式，以 GMP 核验。证书格式保持 `lia_ray`、version 1。局部搜索失败不会报告 UNSAT 或有界。

## 方向局部搜索怎样工作

[方向后端](../../z3-nia/sls/src/nia_omt_direction_sls.h) 直接接收整数系数、等式／不等式与右端项，不使用 Z3 AST 或其他求解后端。

1. 对齐次等式构造有理零空间，并逐列清分母，得到保持等式的整数联合移动基。
2. 在等式消元后的残差中识别互为相反的齐次不等式，补入其蕴含的等式并重复处理。这避免局部搜索在必须联动的边界上只做单坐标修改。
3. 在自由参数上执行临界点修复、加权违约评分、权重调整和重启。随机数由后端私有持有，不消耗原 SLS 的 RNG。
4. 找到候选后精确检查全部原始方向行，随后再经过独立完整射线核验。

系数和方向均为任意精度，保留原来大于 signed128 的证书能力。等式修复只改变候选生成方式，剩余不等式由局部搜索处理，没有 Z3、LP 或 Optimize 后备求解器。

## SLS 信息怎样影响固定集

[优化主流程](../../z3-nia/sls/src/nia_omt_optimize.cpp) 收集实际搜索过程中的三类饱和计数：

- 已接纳 SLS 改善中，哪些变量发生变化；
- 已执行动作中，哪些变量真正移动；
- 动作执行后，哪些受影响子句仍未满足，以及相应惩罚权重。

这些信息作为“固定该变量可能损失多少搜索自由度”的软偏好，优先保留活跃变量自由。缺失历史时退回静态策略，原八种固定规则仍保留。

方向搜索失败后，将实际违约行的压力映射回**代入前**的多项式因子，选择相关固定变量提高其再次被固定的代价，再重新构造满足精确线性化条件的固定集。这样允许交换锚点，而不会因残差中已经消去固定变量就丢失它们的来源。反馈是启发式信息，不是逻辑冲突证明。

所有尝试仍共享原先的无界探测预算，通常最多约 5 秒。重复固定集跳过后，剩余时间用于从本轮最好候选续搜，而不会直接丢弃。旧证书方向、固定集和文字见证没有作为新搜索输入。

最终事件增加 `unbounded_direction_backend`、`unbounded_direction_steps`、`unbounded_guided_attempts`、`unbounded_fixed_set_adjustments`。兼容字段 `unbounded_queries` 现在统计方向局部搜索调用次数。

两轮共有 2362 个曾成功的实例，按 native 结构与基点去重后为 **2827 项**。旧后端与新后端均以每项 5 秒、16 并行重放：**2827/2827 成功，所有新证书通过独立 Python 整数核验，0 回退**。4711 份原始 A1 证书也已核验，再仅提取基点作为重放输入。

第一轮新后端有一项遗漏。定位后发现等式消元才显现的隐含耦合等式，补上通用联合移动处理后，该项约 0.2 秒成功；随后重新完成全部 2827 项回归。保留失败经过，不以单例修复代替最终全回归。

其他检查：

- 独立方向单测、无界语义单测均通过，新增了活动引导固定、饱和计数和失败固定集交换测试。
- 方向后端的 ASan、UBSan 和泄漏检查通过。
- 现有端到端回归 68 项，结果通过，其中 1 项按原有条件跳过。
- 三个实际 CLI 种子均在两次可行值接纳后证明无界，后端为 `sls`，且 `unbounded_guided_attempts=1`，确认生产统计链确实被消费。
- 方向对象文件没有 Z3 调用符号；独立 Makefile 测试不链接 Z3。

这是**固定基点认证回归**，尚未重新进行完整 1200 秒优化实验。它说明新模块能从这些旧基点重新构造无界证书；重新运行完整搜索时的轨迹与总体 A1/A2 数量仍需另测。
