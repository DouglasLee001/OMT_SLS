**贡献一：目标阻塞感知的局部改善搜索。**

这部分应围绕一个问题展开：一个可行点无法直接改善，究竟是目标变化选得不好，还是其他变量尚未给该变化腾出空间？当前实现分别处理“需要不等幅联合改变目标坐标”和“先在同一目标水平上调整其他坐标”两类障碍。比笼统的“结构化邻域”更值得写的是下面两种具体构造。

第一种是严格目标前沿探测。`nia_omt_optimize.cpp:415` 的 `frontier_probes` 先给一个目标变量提出试点，再对另一个变量求使目标接近当前值减一／加一的根附近整数。随后，`project`（`:279`）保护请求修改的坐标，有限轮修复等式和守卫定义；候选通过完整约束验算后才可成为新的最好解。

例如最小化 `x*y`，硬约束为

\[
x\ge3,\quad y\ge4,\quad 2x+y\ge13.
\]

在 `(3,7)`，目标为 21。只增加 x 会使目标变差，只降低 y 会违反约束；等幅反向交换 `(4,6)`、`(5,5)`、`(6,4)` 的目标分别为 24、25、24。但是令 x=4，再围绕 `4*y=20` 求整数试点，便能得到可行的 `(4,5)`，目标为 20。**搜索由严格目标前沿决定联合变化的比例，而不是先随机挑两个变量再期待目标碰巧改善。** 该例只说明这个候选生成机制的动机，不表示已有其他启发式一定找不到同一点。

评分中还包含自身最好值的虚拟严格改善惩罚。探索状态可以暂时违反硬约束；已经进入优于 incumbent 的目标区域时，修复动作会保护这一改善方向（`:989–1007`）。最好可行解与探索状态分离，不可行状态不会被当成优化结果发布。

需要明确它不是通用、完备的两变量优化器：前沿探测要求直接目标支持变量为 2–8 个，还受总变量数、运行阶段和调用频率限制。依赖投影同样只执行有限轮。论文必须给出适用条件，不能画成每个实例、每一步都执行的过程。

第二种是冻结目标阻塞压力的平台搜索。代码在 `nia_omt_optimize.cpp:475–529`。当前点已可行却没有选中严格改善动作时，先模拟目标相关变量的单位改善；从这些探测中提取对硬线性不等式造成的残差增量 `s_j>0` 及目标收益 `g_j>0`。本平台阶段冻结这些探测信息，使用

\[
P(x)=\sum_j g_j\max\{0,\delta_{\ell_j}(x)+s_j\}.
\]

其中正不等式文字的残差满足 `delta<=0`；负文字采用整数补集残差 `1-delta`。搜索只接受完整硬约束仍成立、目标不变、P 严格下降的动作。候选主要从非直接目标的决策变量产生，定义传播仍可能带动其他坐标变化。

一个与现有测试相符的例子是最小化 r：

\[
1\le r\le3,\quad0\le p,q\le2,\quad p+1\le r,\quad q+1\le r.
\]

在 `(r,p,q)=(3,2,2)`，直接令 r=2 会同时违反两条约束。冻结探测 `r:3→2` 后，在 r=3 等值平台上，阻挡 r 下降的相关压力为

\[
P=\max(0,p+2-r)+\max(0,q+2-r).
\]

完整压力场还可能含由 r 下界产生、但在该平台上恒为零的项。先把 p 改为 1，再把 q 改为 1，硬约束与目标值 3 均不变，而 P 从 2 降到 1、再降到 0；此时 r=2 成为可行改善。这里“不改善主目标的移动”有明确作用：为已经观察到的目标改善探测消除阻塞。

这可以支撑一个简单但有用的命题：**在一次冻结压力场的阶段中，每个接纳的中性动作都严格降低非负整数 P，因此该阶段不会发生状态循环，接纳步数至多为初始 P。** 代码另设最多 64 步的限制。这个命题不保证最终一定找到改善；P 只考虑已抽取的硬线性不等式，不能代表全部非线性和布尔障碍。

`test_optimization_neutral.cpp:70–145` 先穷举小域确认初始点没有单坐标严格改善，再检查中性移动的完整可行性、主目标不变及压力严格下降，最后观察到改善；也覆盖最大化和负不等式文字。**这是机制正确性的证据，不是全集性能收益的证据。** 目前多个动作共用 `origin=sls`，旧结果日志不足以逐个归因。

第一项贡献可表述为：“我们通过严格目标前沿探测构造联合改善动作，并由目标探测导出的冻结阻塞压力组织可行等值搜索，从而协调目标变化、约束恢复与平台穿越。”

边界必须交代：双变量与补偿动作在 [PairLS，FM 2024](https://arxiv.org/abs/2406.15782) 中已有；保持目标值的平台移动在 [NILS](https://arxiv.org/abs/1207.4450) 中已有；自动按约束结构构造邻域在 [A Framework for Constraint Based Local Search using Essence，IJCAI 2018](https://www.ijcai.org/proceedings/2018/0173.pdf) 中已有。这里需要比较的是**非线性严格前沿的具体生成方式，以及目标阻塞探测导出的冻结压力规则**，而不是泛称首次联合移动、首次平台搜索或首次结构化邻域。

因子覆盖下的 LIA 大邻域修复可以放在这一贡献的技术子节。`nia_omt_bilinear.cpp:335–475` 对约束和目标的全部单项式选覆盖，固定后每项剩余自由总次数至多一；完整 CNF 加严格目标界交给本地 `LiaSolver`。二分因子图可以逐连通分量选择不同颜色类，其他多项式回退到一般覆盖。该部分扩展可调整变量的规模，但固定因子线性化本身不应再被称作新思想。

常量 ITE／定义链识别也有实际价值：恢复真实决策坐标，减少在派生辅助变量上反复搜索。它适合作为低层 SMT 编码适配说明。一般输入／输出变量和不变量传播在 CBLS 中已有成熟研究，见 [Invariant Graph Propagation in Constraint-Based Local Search，JAIR 2025](https://justinkennethpearson.github.io/files/pubs/papers/2025_jair.pdf)。

**贡献二：失败可追溯的无界证书合成。**

这部分最值得写成算法的是一个闭环：**优化轨迹统计 → 选择要固定的非线性因子 → 搜索永久改善方向 → 将失败压力追溯到代入前因子 → 重建固定集。**

`nia_omt_unbounded.cpp:284–310` 使用改善活动、实际移动与违约子句压力，形成保留变量自由的分数：

\[
S(v)=4\log(1+I_v)+\log(1+M_v)+\sum_{c\ni v}\log(1+C_c).
\]

分数低的因子优先固定为当前已验证基点的值，直至所选文字与目标均仿射。它是启发式偏好，不是证明前提；没有搜索历史时会跳过该指导尝试，原八种静态规则仍保留。

更具体的设计是保留被代入变量的来源。方向约束的残差中已经不再出现固定变量，只查看残差的违约变量，可能恰好看不到错误的固定选择。代码 `:429–431` 为方向行保留原始多项式的变量集合；`:472–493` 将违约压力映回原因子，提高相关固定变量的保留自由分数，再重新构造线性化覆盖，最多四次。它不是被删除的 UNSAT core 路径，也不把方向搜索失败当作切片不可行的证明。

现有真实单测 `test_omt_unbounded.cpp:164–167` 可以直接改写为论文例子：最大化 `x*y`，约束 `y=2`，基点 `(3,2)`。若先固定 `x=3`，方向问题同时要求 `d_y=0` 和 `3*d_y>=1`，找不到方向。此时目标残差已经没有 x；保留原乘积 `x*y` 的来源才能把失败压力追溯到固定的 x。改为固定 `y=2`，就得到 `d=(1,0)`：

\[
(x(t),y(t))=(3+t,2),\qquad f(t)=6+2t.
\]

该测试实际要求发生固定集调整，不只是事后可以解释的示意图。

方向后端本身还有值得写清的结构设计。`nia_omt_direction_sls.h:98–177` 先构造保持齐次等式的有理零空间，并逐列清分母形成整数联合移动；消元后若两条齐次不等式互为相反约束，则把其蕴含的等式加入闭包。剩余不等式再交给方向 SLS。这使方向搜索不必反复破坏必须同时变化的等式边界。

可以加入一个表示覆盖说明：逐列清分母并不保证覆盖整个整数核；但对于这里的“齐次方向锥加严格改善斜率”问题，任意可行方向的有理基坐标乘公共分母，会得到整数参数和整体放大的可行方向。齐次约束与严格改善仍成立。因此这种参数化不会仅因选了有限指数的整数子格就消灭射线的存在性。该结论是标准代数性质，且不意味着有限预算 SLS 完备；非齐次一般整数问题不能直接套用。

最终核验器 `nia_omt_unbounded.cpp:225–262` 独立重读 native CNF 与多项式，检查文字覆盖、固定及布尔坐标方向为零、仿射残差的永久保持条件和目标严格改善斜率；不以生成的方向行充当核验依据。由此得到

\[
\text{接受证书}\Longrightarrow
\forall t\in\mathbb Z_{\ge0},\ F(a+td),\quad
f(a+td)\to\pm\infty.
\]

直接输出的证书针对 native 表示；向原 SMT2 转移结论还依赖目标值集合保持的导入关系。固定因子后的仿射限制也会漏掉可行曲线以及依靠高次项沿轨迹抵消的射线；负等式还固定当前符号分支。失败只表示没有找到证书。

这一贡献可表述为：“我们利用优化过程统计选择用于认证的线性切片，并将方向搜索失败压力追溯到代入前的非线性因子以调整固定集，在等式保持的整数方向空间中合成并精确核验永久改善射线。”

新颖性边界：[FroCoS 2021](https://es-static.fbk.eu/people/griggio/papers/frocos21.pdf) 已有模型引导的固定因子线性欠近似及无界结论传递；[Exploiting Partial-Assignment Enumeration in OMT，FroCoS 2025](https://link.springer.com/chapter/10.1007/978-3-032-04167-8_7) 已讨论完整真值赋值过度限制优化。因此不能把固定线性化、少固定一些文字或射线判据本身写成首创。一般加权违约局部搜索也已有 [Feasibility Jump](https://link.springer.com/article/10.1007/s12532-023-00234-8)。主要区别必须落实到这里的**切片选择与代入前失败来源反馈**。

**已有无界实验能支持到哪里。**

保留的 [2827 项回放报告](/data/shared/lbh/OMT/result/NIA_20261102_171431_909766/summary.md) 是重要的模块证据：旧 Z3 方向后端与新方向 SLS 从相同基点、每项 5 秒重新构造证书，均 2827/2827 成功，且新证书全部通过独立 Python 整数核验。模块中位时间为 0.020697 与 0.004808 秒；不能将这个中位数之比解释成整个求解器加速倍数，也没有完整分布与重复试验来支持稳定速度结论。

这批回放实际调用 `test_omt_unbounded_replay.cpp:43` 的三参接口，经 `nia_omt_unbounded.cpp:336–339` 传入 `nullptr` hints，**没有外层 SLS 历史统计**。因此它测试的是方向后端、静态固定策略及内部失败反馈的组合，不能用来证明外层活动分数的效果。2827 项来自已知历史成功基点，也不能作为对全部未解决实例的覆盖率。

**第三候选：由自身目标界参与构造的守卫多项式放松。**

“调用 Z3 检查更优解是否存在”不应作为贡献，但当前代码还会主动改变交给证明器的问题。`nia_omt_guarded_product.h:200–284` 在完整原式及自身严格目标界上，生成带守卫的“等式乘变量”和“非负事实乘事实”后果，按共享单项式库存控制最高三次的扩张，再把单项式提升为独立实数坐标，形成 QF_LRA 必要放松。原完整布尔结构保留，不固定 incumbent 的坐标。

这里的“完整原式”限于当前支持片段：原式整数多项式次数至多二，算术原子通过 AND／OR／NOT 及 true／false 组合。三次项来自后果扩张；独立自由 Bool 符号、ITE、div/mod、高次原式等会使该辅助阶段保守回退。不能写成对任意 QF_NIA 都构造这一放松。

例如 `x>=0,y>=0,z=x*y`，最小化 z，已找到 M=0。只将乘积提升为独立坐标 P，放松可以取 `X=Y=0,Z=P=-1`，仍不能排除严格改善。当前代码会依据库存中已有的 `xy`，生成

\[
(X\ge0\land Y\ge0)\Rightarrow P\ge0.
\]

它与 `Z=P`、`Z<=-1` 构成线性冲突。若事实只在某些布尔分支下成立，对应后果必须带守卫，不能把当前模型分支变成全局硬约束。

可靠性方向为：每个原整数模型把提升坐标解释为真实单项式值后，都满足这些守卫后果；故必要放松 UNSAT 推出完整严格改善问题 UNSAT，再结合已验证 incumbent 得到 A2。生成预算截断只会减弱放松。放松 SAT 不能作为原式模型发布。

这里值得考察的是**目标界参与后果组织、受单项式库存约束的后果选择，以及适用于布尔组合的全局认证**。其基础是 RLT／多项式线性化，不能将“乘约束再线性化”或“选少量后果”本身写成新思想。相关基础见 [Sherali–Tuncbilek 1997](https://www.sciencedirect.com/science/article/pii/S0167637797000138)；还应纳入 [Revisiting Incremental Linearization for Nonlinear Integer Arithmetic，2026 预印本](https://arxiv.org/html/2608.04835v1)。后者研究模型驱动的高次单项式公理和线性界，不能因为我们使用 QF_LRA 而略过相关工作比较。

已有证据见 [优化尝试记录](优化尝试记录.md)：329 例诊断得到 19 条及时界证明，预选这 19 例接入后均从历史 B/0 变成 A2/0；这说明有真实证明价值，但有成功子集选择。历史 native013 完整实验保存了 692 份最终 A2 实际引用的 guarded 转换核验，不能称新增解决 692 例。该版本同时启用 BV 等变化，整体净增 32 不能全部归因给此模块；转换核验也不等于重放底层 LRA UNSAT 证明。

还需避免一个已有归因错误：shared 与首项索引版本的原始 UNSAT 集合都是 19，及时验收从 11 到 19 来自检查器修正。首项索引可以作为控制生成成本的实现设计，但现有数据不能证明它新增了 8 条数学证明。

所以这是**可进一步争取的第三项贡献**，尚不应和前两项并列宣称独立新颖、独立有效。最直接的后续验证是同二进制、同种子、同预算的 guarded OFF/ON，再分开比较基础乘积后果和共享三次闭包；索引只评价生成成本及截断行为。

**可以形成哪些理论内容。**

| 性质 | 论文作用 | 不应扩大的结论 |
| --- | --- | --- |
| 冻结压力为非负整数，每次中性接纳严格下降 | 平台阶段不循环的短命题 | 不保证最终存在或找到更优解 |
| 覆盖固定后，全部剩余单项式自由次数至多一 | LIA 修复子问题及模型补回的正确性 | 固定集失败不证明原问题不可改善 |
| 齐次方向锥在清分母后的基空间中保留射线存在性 | 等式保持方向搜索的表示说明 | 不覆盖一般非齐次整数可行性，不使 SLS 完备 |
| 文字覆盖及仿射斜率核验推出永久可行、严格改善 | 无界证书可靠性 | 不覆盖所有无界 NIA 问题 |
| 原整数模型映入带守卫的必要 LRA 放松 | 有限最优认证的可靠性 | 放松 SAT 不是原式 SAT；不等于新的 RLT 理论 |

这些性质使方法可理解、可复现，但“能写出正确性命题”并不自动等于新理论贡献。

**实验和资源也可以是贡献，但需独立定位。**

`new_benchmark` 已有 portfolio、cyclic、packing、design 四类应用，共 566 个优化 SMT2 实例及参数化生成器，可补充原 5744 个实例。可以将模型来源、参数规模、目标形式和生成种子整理为资源贡献，不把应用特化规则混入通用算法；目前核查的生产证明模块没有按这些家族名分流。

现有 [关闭 core 邻域的完整实验](/data/shared/lbh/OMT/result/NIA_20261103_192610_938407/summary.md) 为 6310 例，A1/A2/B/C=2359/3623/304/24，成功 5982；Z3 和 OptiMathSAT 成功数为 3074、3746。该实验使用物理删除前的冻结二进制、关闭对应开关，不应冒充当前 `e2a036c8c` 的同版消融。它能说明系统表现，不能把整体优势分配给某个新启发式。

特别需要拆分有界与无界、original 与 new，以及四个应用类别：总数中的无界优势很大，不应让它遮住有限目标质量和有限最优认证的真实表现。历史目录中的 bounded 来源于按求解结果过滤大目标值，不是对所有剩余例子的数学有界证明，论文不能直接当作真值标签。

**最值得补的证据，按优先级排列。**

1. 对核心 SLS 机制做逐项消融：基础 SMT-SLS 加自身严格目标界；加入严格目标前沿与关联修复；再加入冻结压力平台搜索。中性搜索至少对比关闭、随机可行等值移动、当前压力规则。保持证明调度相同，或先单测搜索端；记录调用、改善次数及时间，不只保留统一 `origin=sls`。
2. 对无界切片选择做同基点比较：静态八策略、加入外层搜索活动、再加入方向失败来源反馈。需要真实保存的搜索统计；不能把当前无 hints 的 2827 回放当成第一层活动指导消融。
3. 在相同文字、固定集和预算下比较方向 SLS 与原 Z3 方向查询；再对比同一线性切片直接交给线性 OMT 检查无界。这样才能区分切片选择、方向后端和证书输出的贡献。
4. 增加“其他求解器给出的可行基点＋相同认证模块”的受控诊断，判断优势来自更好的基点、切片选择还是认证器。该诊断单列，若作端到端比较必须计入全部时间，不替换竞品原生结果。
5. 若保留第三候选，做 guarded 单独 ON/OFF 及后果强度对照。已有 19 例是发现方法的诊断集，还应在完整集或独立保留集验证。
6. 对随机搜索使用相同实例、相同预算和匹配机器的多个种子；同时报告目标质量、成功状态及运行时间。已有不同节点、不同二进制的单次比较不能替代这些机制消融。

以上是待做实验设计，本次没有执行或修改求解器。现有实现未为所有子机制提供独立开关，不能把这些设计直接当成已可提交的命令。

**建议的论文组织。**

引言只列两项核心算法贡献，加一项系统与实验贡献。方法开头给总伪代码，随后展开“目标改善与阻塞压力”和“搜索反馈驱动的无界证书合成”；完整原式严格改善查询、SAT 回灌及调度放在总体框架中。守卫放松若经进一步对照支撑独立收益，再升级为第三个算法章节；否则作为有限最优认证的增强子节。

可用的贡献段落是：

> 我们研究非线性整数优化中的目标改善与无界认证。首先，通过严格目标前沿探测构造关联变量的联合改善动作，并以目标探测导出的冻结阻塞压力组织可行等值搜索。其次，利用优化轨迹与方向搜索失败的原始因子来源，自适应选择用于认证的线性切片，在等式保持的整数方向空间中合成可精确核验的改善射线。最后，将这些过程与完整原式的有限最优检查集成为求解器，并提供应用实例生成器和可复现实验评价。

这里明确提出机制，不预先填入“首次”“显著提升”或单组件收益。被删除的 core 指导、未启用的 integer-affine convex、objective-slice、slack、tail 原型，以及尚未实现的 VSIDS／activity 深度交互，均不能写成当前方法的组成或效果来源。
