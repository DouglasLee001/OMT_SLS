# 应用 OMT(NIA) 生成实施计划

目标：在一个目录中合并重叠场景，生成具有应用目标、精确整数算术和可独立检查见证的新实例。遵循用户的目录偏好，不改现有 benchmark 和批量运行脚本。

设计：每个应用唯一目录包含 src/、instance/、README.md；共用标准库框架 src/nia_bench 负责 CLI、确定性序列化、来源、去重和 Z3 限时核验。模型构造与应用解检查分开计算。全部实例有 base.smt2 和 opt.smt2；原来源重放与新构造在元数据和清单中区分。优先完成指南四类；管道依本地完整来源单独核对，TSN 和齿轮不进入主 NIA 集。

- [x] 比较旧资料、新指南和 19 个参考小样，记录应用合并和实例去重边界。
- [x] 先写共同框架的确定性输出、错误见证、理论边界和最优值核验测试，再实现框架。
- [x] 持仓：四个精确 MINLPLib 重放、风险微型回归、4/8/16 资产各两种子合成 Gram 风险。
- [x] 循环调度：四个 MiniZinc 重放、非零 k 微型 A/B、6/12/24 真实任务各两种子 planted 实例。
- [x] 排样：n=1..10 方块、6/12/24 工件各两种子固定方向矩形，几何独立检查。
- [x] 实验设计：二维及有理缩放回归、三个参考整数数据、d=2..5 的组合规模和两种子；矩阵与 Cauchy–Binet 两路径核验。
- [x] 审核管道来源并决定可严格说明的独立新构造范围；记录其与官方源码的差异。
- [x] 对所有生成实例做前端解析和固定见证 SAT 检查；每例短时尝试 Z3 优化，保留原始输出和超时状态。
- [x] 微型例用精确枚举或严格改进 UNSAT 核验，重生成对比语义文件哈希，汇总来源、计数、命令和限制。
