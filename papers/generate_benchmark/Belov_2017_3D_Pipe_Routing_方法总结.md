# Belov 等（CP 2017）：3D 管路柔性模型怎样形成 OMT(NIA) benchmark

本总结面向整数非线性算术优化 OMT(NIA)。结论是：这篇论文的 Guided Cantilever Method（GCM）把管段长度的三次项保留在约束中，因此很适合构造有工程来源的有限域整数优化实例。已经找到并收集了 **5 个官方公开的原非线性 MiniZinc 管路子问题**；后续可先忠实翻译这些现有实例，再从固定喷嘴、轴向路径、障碍、支撑区和正的柔性系数组合生成新实例。这里仅收集和分析，未实现生成器、未生成 SMT-LIB benchmark、未运行优化器。

须分别保存两种语义：①官方 Challenge 源码实际采用的取整柔性系数、缩放目标；②按论文式(7)–(11)使用精确有理参数重建的模型。它们都能得到 NIA，但不能混称同一个实例。论文实验是逐条管路优化，固定前面管路作为障碍；论文表中的全厂总成本不能作为联合模型的 `globalopt`。

## 2. 原论文究竟优化什么

论文把工厂布局拆成两阶段：先安排设备，再固定设备位置设计管路。本文只详细给第二阶段；设备选址模型没有完整公布在文中（pp.323–325，§2、§3）。因此新的管路 benchmark 应把设备位置作为输入常量，不把设备旋转、设备间布局或设备选址成本偷偷加入原模型。

目标是降低管路长度、90度弯头与支撑的成本，并满足几何、安全距离和热膨胀柔性。管道只允许沿 x/y/z 轴铺设，弯头为90度；几何碰撞用方形截面长方体近似管段，暂不考虑真实弯曲半径（p.324）。这保留了离散几何和工程三次关系，但不是全尺寸真实圆柱 CAD 或精确应力分析。

原论文的实验算法（pp.330–331，§5.2）依次为各管路求解：设备、其他管路喷嘴附近的段、先前已求出的管段，成为当前固定障碍。顺序以近似长度乘宽度的表面积大小排序。每条管路先允许最多10段；无解时才增加段数。先不加GCM求最便宜路由，检查应力，只有超限时再加GCM重求。这是求解流程，不等于一个同时最小化全部管路成本的全局模型。

可形成三个明确区分的 benchmark 类别：

| 类别 | 待优化对象 | 固定输入 | 最优值所指 |
|---|---|---|---|
| `single-pipe/source-faithful` | 一条管路 | 官方发布子问题的设备、其他固定管段、喷嘴 | 该固定障碍上下文下的局部管路最优值 |
| `single-pipe/paper-rational` | 一条管路 | 新造几何或提取子问题几何、论文精确有理GCM参数 | 新的精确有理子模型最优值 |
| `multi-pipe/joint-extension` | 多条管路一起可变 | 设备和喷嘴，管路间避障共同求解 | 联合模型最优值；这是扩展，不能套用论文表值 |

## 3. 输入、整数变量和几何骨架

### 3.1 输入组织

按 pp.325–326（§3.1–3.2），需固定以下输入。

| 输入 | 含义及生成作用 |
|---|---|
| 容器三维尺寸、`K≥1` | 原物理长度以毫米给出；一个整数坐标单位为K毫米。K越小，可选位置越多 |
| 固定设备集合 `M` | 每件为小角坐标 `X_m` 与尺寸 `W_m` 的长方体；包括设备、障碍、管架、源/汇 |
| 每条管路的两个喷嘴 | 三维坐标及六种朝向；论文0/1/2为+x/+y/+z，3/4/5为−x/−y/−z |
| 管路参数 | 物理外径D、单位长度成本、弯头成本、最多段数N、安全间距、热膨胀e、弹性模量E、允许应力SA、段长上下界 |
| 支撑区集合 `SZ` | 长方体区域及使用成本；只能由允许支撑的设备或管架区域提供 |

主要变量是节点 `X_{p,i,c}∈Z`。每条管路最多N段、N+1节点，首尾喷嘴固定，其余节点可变。段存在标志 `f_{p,i}∈{0,1}`，方向、轴向非负长度 `L_{p,i,c}`、管段长方体边界是辅助变量。所有坐标及长度都应给有限整数上下界。长度与相邻节点的绝对差一致，实际段只在一个轴上为正，其他两个轴为0。

若实际只用n段，后面的N−n段为0、尾部节点重复终点。原式(1)规定 `f_i≥f_{i+1}`，把存在段排列在前。式(2)规定后一段存在时，相邻段轴不同；既禁止同轴合并重复表示，也禁止180度折返。SMT中可把方向轴用有限布尔分支表达，无需保留`mod`。

### 3.2 对应原源码的细节不能忽略

公开 [routing_GCM_0001.mzn](sources/pipe-routing/routing_GCM_0001.mzn) 并非只给抽象模型；第一部分已自动展开节点域和固定障碍数组。其节点坐标甚至有负下界，说明已使用具体坐标系；翻译时不应擅自全设为非负。源码方向是 **0表示无段，1/2/3为正方向、4/5/6为负方向**，与论文0–5约定不同。

该源码 `nRadius = nDiam div 2`（0001第162行），管段三轴下界为节点最小值减半径，上界为最大值加半径（第213–224行），连轴向端点也加半径。论文只描述长方体近似，没有给出这一步全部细节。因此论文重建模型须写明自己的hull定义；原源码翻译则保持其`div`及包围体规则。

源版还强制每条管路至少3个实际段（0001第225–233行），而论文抽象描述只给最大段数；新实例采用2段或1段时属于论文模型重建，不能说与比赛文件逐字等价。源码对未用尾槽、动态最后一段和终点重复有专门标志；不应仅固定最后一个槽为终点却漏掉“最后实际段接终点”。

几何外径格点值与GCM物理直径可能不同。例如0001的 `K=200mm`、`nDiam=4`对应包围体宽度800mm，而GCM常数64.346183605662020可由论文应力参数配物理D=750mm重现。后续生成器应分别记录“物理外径”和“栅格碰撞宽度”，明确向上取整或原源码规则；不能用800mm回算柔性却声称忠实保留750mm物理参数。

### 3.3 避障、喷嘴例外与支撑

原式(3)（p.327）以六向分离析取避免管段长方体与设备碰撞：至少一个轴c满足

`pipe_lo[c]+pipe_size[c]+s ≤ equipment_lo[c]`

或者

`equipment_lo[c]+equipment_size[c]+s ≤ pipe_lo[c]`。

不同管路管段间采用同样六方向分离。在SMT中每对物体写一个`or`，不用Big-M、不引入实数松弛。安全间距系数和直径若为有理数，可用整数统一几何尺度，或整体乘正分母再比较。

喷嘴段与所属设备连接时必须有例外，否则安全距离与实际接触冲突。论文式(3)作为示例没有写出例外；原源码0001第281–289行明确免检起始喷嘴段对应设备，终端设备也允许最后实际段和不活动槽。新模型必须写明附件设备ID、入/出方向、哪些段能接触设备，而不是普遍移除起始/终端设备全部碰撞约束。

源码第290–300行只检查**不同管路**之间的段碰撞；同一管路段间自交没有被这一约束排除。为非相邻本管段另加避障是可以研究的加强版，但要标记为新增约束，不能默默当成已发表代码语义。

论文式(4)–(5)（p.327）要求弯头的基点处在至少一个支撑区；式(4)写作按 `tilde X` 的三坐标闭区间包含。已收集代码的具体判断更细：x/y用**节点中心**，z用**节点高度减半径，即管道底部**（0001第301–327行）。论文符号与源码几何锚点并不完全相同。两个版本应明确记录采用哪种支撑锚点。

原式(5)及源码的支撑要求没有按存在标志完全跳过尾部重复节点。因此如果保留源语义，终点及重复尾槽也须落在允许支撑区。只对真实弯头加 `f_i=1 → support` 是较自然的新模型，但属于语义调整。

支持仅设在弯头，是论文的简化；长直管段可能另需支撑，论文承认最大实例出现过一次这种情形（p.327）。不能把“只要求弯头支撑”宣称为完整工程支撑检查。

## 4. 成本目标与支撑分支

按 p.326及p.327式(6)，目标是每条管路的长度费用、弯头费用、支撑费用之和：

`C = Σ_p [ CL_p Σ_i Σ_c L_{p,i,c} + CB_p Σ_{i=2..N_p} f_{p,i} + Σ_{i=2..N_p} CS_{p,i} ]`。

段长轴和只含一项非零，因此等于总路由长度；第i≥2个存在段的起点对应弯头。式(6)的特殊两档支撑成本为

`CS_{p,i} = CSZ_p · f_{p,i} · (1 − Σ_{j:cost(j,p)=0} bSZ_{p,i,j})`。

它依赖零价支撑区互斥：同一锚点最多属于一个零价区。如果多个闭区间边界重叠，求和可能大于1、费用变成负数。生成时应让免费区域严格分离，或选择不相交整数区间；改成“只要任意免费区成立费用就是0”的`ite`是更通用的模型扩展，需要标记这种差异。

原文默认实验的费用（p.330）：单位长度$25–400/m、每弯头为该管每米价格的2倍、需收费支撑的弯头为每米价格10倍；地面0–3m层与管架优先层免费。弯头/支撑是一次性价格，并非另乘弯头几何长度。这些是公开展示参数；论文明确真实费用和应力值不能披露。

如果目标参数是精确正有理数，只要所有项一起乘相同正公分母Q，就可把目标化为整数并保持全部解的排序。费用缩放必须同时涵盖长度（K毫米转换到米）和所有一次性费用。分别向上/向下取整每个系数会改变权衡，不是保持最优解的统一尺度变换。

比赛源码采用另一目标：`nOBJCOEFDIVISOR=100`，各费用系数取`cost div 100 + 1`（0001第143、338–342、401–408行）。即使原支撑层成本0也会贡献+1。此操作会改变相对权重；为了复现比赛子问题，必须保留其实际目标、`objective∈1..10000000`，不能用论文美元目标替换后引用比赛最优值。论文精确费用版则不必继承为特定CP求解器设计的目标上界，但应由有限变量域推导一个不会排除可行解的界。

## 5. 三次柔性关系：公式、方向分支与单位

### 5.1 原式与适用前提

GCM假定管路只在喷嘴两端固定，采用直角弯头（p.327）。对轴a，令喷嘴净距离为 `N_{p,a}`，不是管路所有该轴段长的总和。原式(7)热膨胀为 `Δ_{p,a}=N_{p,a} e_p`。

令

`T_{p,x}=Σ_i [L_{p,i,y}^3+L_{p,i,z}^3]`，

其余轴按循环置换。非零段沿轴b，若b≠a，原式(8)分配的横向挠度为 `δ_{i,a}=L_i^3 Δ_{p,a}/T_{p,a}`。沿a的段不吸收a向横膨胀，不对该轴套这条公式。原式(9)允许挠度为 `δbar_i=48 L_i^2 SA_p/(E_p D_p)`，式(10)要求各适用横向挠度的最大值不超过允许值（pp.327–328）。

在 `L_i>0`、`T_{p,a}>0`、`E_p,D_p,SA_p>0` 下，交叉相乘并约去 `L_i^2` 得式(11)：

`κ_{p,a} L_i ≤ T_{p,a}`，其中 `κ_{p,a}=Δ_{p,a} E_p D_p/(48 SA_p)`。

必须展开六种段轴/热膨胀轴分支：

| 实际段方向轴 | 要检查的热膨胀轴 | 三次和 |
|---|---|---|
| x | y与z | `T_y=Σ(L_x³+L_z³)`；`T_z=Σ(L_x³+L_y³)` |
| y | x与z | `T_x=Σ(L_y³+L_z³)`；`T_z=Σ(L_x³+L_y³)` |
| z | x与y | `T_x=Σ(L_y³+L_z³)`；`T_y=Σ(L_x³+L_z³)` |

正/负轴向都使用绝对段长；反向绕行不改变喷嘴净距离N，也不以路由长度替代Δ。若某轴喷嘴净距离0，则κ=0，该轴没有非零膨胀要求。存在标志0的段所有长度0，不可把原挠度式中的0/0当成有效应力计算。

### 5.2 常数48不能直接照搬到毫米同单位公式

论文参数来自英制工程例子（p.330）：`e=0.078 in/ft`、`E=29·10^6 psi`、`SA=21625 psi`。源码0001第378–389行明确用 `q=K/304.8`（一个格点等于多少ft），并预先提供`dGCM_Cpp`。因此式(9)常数48的数值搭配为 **L用ft，D和δ用in**，E和SA用一致压力单位；直接把所有长度数值都用mm仍保留48会产生错误模型。

具体换算如下。记物理毫米直径 `D_mm`、整数段长 `l`、整数喷嘴距离 `n`；取 `q=K/304.8 ft`、`D_in=D_mm/25.4 in`，定义

`C''_p = e_(in/ft) E_p D_in /(48 SA_p)`。

代入物理段长 `L=q·l`，得到整数格点中的正确系数

`β_{p,a} = C''_p · n_{p,a} / q`，

然后约束 `β_{p,a} l_i ≤ Σ_{j,b≠a} l_{j,b}³`。

如果统一把所有长度改为mm，则 `e_mm/mm=0.078/12=0.0065`；由英制转换得到挠度容量为 `δbar_mm=L_mm² SA/(3 E D_mm)`，而不是带48的同单位式。相应格点系数是 `β=3 e_mm/mm E D_mm n/(SA K)`，与上一式相同。这里是由公开公式与源码换算的推导，不是论文另给的一条新经验公式。

数值核验：`D_mm=750`、`K=200`和论文公开e/E/SA给

`C''=1413750/21971 ≈64.34618360566202`，

`β/n=16965/173 ≈98.0635838150289`。

这与0001第64行的常数一致，说明原源码注释里 `E*D(in)/48/SA` 没有完整写出e，但常数值已经包含e。生成器不可照着不完整注释再次乘或遗漏e。

### 5.3 精确有理化与官方取整版的区别

论文精确参数版：将所有物理输入读取为十进制有理数，而非二进制浮点。设 `β=A/B`，A≥0、B>0，NIA约束就是

`A·l_i ≤ B·Σ_{j,b≠a}(l_{j,b}·l_{j,b}·l_{j,b})`。

不同轴β各自约分清分母；保留真实整数乘法，不把立方查表线性化。E、SA、D、K是输入常量，故非线性次数最高为3。可以引入辅助变量 `u=l·l`、`v=u·l`，仍然是NIA；若改为有限域等值查表，语法上成为线性析取版，应作为不同编码组。

官方源码版：`nCoefL=ceil(dGCM_Cpp·nDeltaNz/q)`，`nCoefReductionFactor=1`，直接施加 `nCoefL·l_i≤T_a`（0001第361、371–394行）。代码中的`float`全部是固定参数/编译期计算，不存在`var float`；最终优化变量都是整数/布尔。翻译成OMT时先计算并记录源码实际整数 `nCoefL`，完全可以保持NIA。

`ceil(β)·l≤T`一般比精确 `β·l≤T`更强。T是整数不意味着两者等价：`β=3/2,l=2,T=3`在精确关系中成立，但取整后要求4≤3而失败。因此不能把精确清分母版称为比赛代码的等价翻译。若要精确复现原编译器浮点ceil，在系数恰好接近整数时应记录编译器版本、计算结果；仅把打印小数解析成有理数再ceil可能在边界处有差异。

### 5.4 零分母、关闭柔性与加强模型

当Δ_a>0却没有任何横向实际段时，`T_a=0`使原挠度式(8)未定义；式(11)若仅对横向非零段发约束，会真空成立。已发布代码对所有横向长度发约束，长度都0时也只得0≤0。因此不要声称原代码独自排除了所有轴向热应力失效。

最稳妥的忠实基准生成做法是约束**输入/保证可行模板**：凡非零膨胀轴，路线模板含足够横向段，且喷嘴朝向与几何条件阻止完全直线退化。若在模型中新增 `Δ_a>0 → T_a>0`，应记作“GCM零容量保护”加强版，不能标为源码等价。若Δ_a=0，则无需利用0/0来判断；该方向要求平凡。

源代码还允许`dGCM_Cpp≤0`关闭柔性计算。这可作为明确的LIA消融对照，但NIA主数据集必须有严格正的GCM参数且含可变的三次项，不能把关闭柔性实例计入核心OMT(NIA)组。

## 7. 如何制造保证可行的小实例

以下是新benchmark的设计建议，不是论文附带的生成器，也没有在本次实施。采用“先构造完整可行管路，再采样其周围数据”可避免随机设备/喷嘴产生大量无解。

1. **先定单位和域。** 固定K、容器、物理D和栅格hull策略，所有输入位置能落在整数网格；半径为分数时用几何坐标乘2或公分母，另行更新单位换算。记录整数尺寸而非只给米数。
2. **构造轴向折线路径见证。** 至少3段以兼容公开源码；连续轴不同，每个段满足2D的最小长度、喷嘴段6m最大长度和全体上界。首尾段匹配喷嘴方向，并固定喷嘴坐标。保证非零热膨胀轴有横向段，不用完全直线管路作为主要见证。
3. **让GCM见证具有裕量。** 对见证逐轴算立方和与所有对应 `β·l`，以精确有理数检查。不要只检查总长；每一个横向段都必须满足对应两轴条件。可先拉长横向回路，然后在正的E/e/D和SA组合中选择能满足裕量的参数。也可从论文公开物理参数开始，按式(11)选回路长度。改变这些参数得到的是论文结构的合成数据，应标记为合成。
4. **放入安全障碍。** 将设备/固定管段放在见证hull加安全间距以外。不要只保证中心线避障；要按完整长方体和六方向分离检查。喷嘴所属设备按附件例外验证。
5. **为弯头放支撑区。** 按选择的锚点规则，在每个真实弯头和需要支持的重复终点附近放区域；保留一个宽松的收费支撑区可保证可行，再加不相交免费优先层用于成本竞争。支持区不是障碍实体；把支撑区当障碍会误删可行管路。
6. **保持路径可变。** 见证用于SAT证明及检查，不把全部弯头坐标固定到见证。给附近整点范围、额外段槽和替代支撑区；让目标有路由选择，并确保剩余变量的立方项无法全部常量化。
7. **保存证据。** 输出输入seed、模板、见证节点/段、原模型版本、精确系数、目标缩放、完整约束检查和见证成本。见证证明可行并给上界，不证明最优；后来证得最优须验证 `C<C*` 无解。

### 一个可手算的可行模板

采用整数毫米单位 `K=200mm`、物理D=200mm，e/E/SA取论文公开数值，得到 `C''=377000/21971`、`q=200/304.8`，即整数格点 `β/n=4524/173`。容器 `[0,25]^3`（5m立方体），节点取

`(2,2,2) → (2,17,2) → (14,17,2) → (14,2,2)`。

三段为+y长15、+x长12、−y长15；喷嘴净距离x=12、y=z=0。`T_x=15³+15³=6750`，两条横向段的柔性左侧都是 `(4524/173)·12·15=814320/173≈4707.052<6750`；y/z因净膨胀0要求平凡。每个喷嘴段15格=3m≤6m；段长大于2D=400mm=2格。见证hull留在容器中；两个真实弯头及需要检查的终点设为可支撑，远处障碍置于见证安全包围体外即可。

具体可取一个地面支撑区 `(0,0,0)`、尺寸 `(25,25,15)`（高度3m），作为唯一零价支撑区；所有见证弯头和终点底部均在其中，不会发生免费区重叠。加一个固定障碍 `(18,18,18)`、尺寸 `(3,3,3)`，安全间距取1格=200mm：见证管路最高hull为z=2.5格，加间距为3.5格，严格低于障碍z下界18格，六向分离成立。该200mm安全距是合成参数，区别于论文默认75mm。如果采用论文默认75mm，也可精确乘几何分母清除，见证仍安全。喷嘴可作为不附加实体设备的固定源/汇；若增加所属设备，必须重新验证仅喷嘴段允许接触的例外。

取长度费用$25/m、弯头$50/个、免费地面支撑，见证总长8.4m、有2个弯头，费用为$310。这个数只可记作 `feasible_cost` 上界；没有对所有其他路径证明最优，不能记作`globalopt=310`。

这一模板符合整数毫米K输入，并采用论文参数；它仍是合成小布局，不是原工业实例。物理半径100mm为半格，若按精确物理hull，几何分离式整体乘2即可使用整数边界 `2·X±1`。如果选择忠实于比赛源码的 `nRadius=nDiam div 2`，则要按源码重建/另选偶数栅格直径，不能将这两种包围体假设混称为同一实例。

要使柔性更接近瓶颈，可缩小回路或增加物理D/热膨胀，直到最紧比率 `β·l/T`接近1但仍严格可行。由于立方和随长度快速增大，回路存在与目标罚长会形成真正的长度—柔性竞争。为了避免只得到“所有GCM约束很松”的易例，可分别保留应力裕量大/中/小的组别，并检查无GCM最便宜路径是否违反GCM。

## 8. 可控扩展维度与哪些修改有意义

论文原有扩展方式（pp.329–333）：从默认设备/管路取子集，并把K从200mm降到100mm。默认容器76×40×43m，整数位置点381×201×216，设备17件、管路27条、物理D为50–750mm，安全距75mm；较小数据设备/管路数是13/17、9/10、5/3。默认支撑区为设备周围3m带、管架3/6/9/12m高的50cm厚优先层，以及地面0–3m层。

可据此设计新组别：

| 维度 | 建议取值/变化 | 如何保留可行性与NIA价值 |
|---|---|---|
| 可选段数N | 3、4、6、8、10及更高 | 见证所需段数不超过N，尾槽语义保持；增加N扩大拓扑而非仅多加0变量 |
| 坐标网格 | K=400、200、100mm，或容器整点域扩大 | 同一物理布局细化时重算半径、间距、喷嘴及β；别只放大坐标保持柔性系数 |
| 固定障碍数 | 从0到几十/上百 | 与见证保持安全分离，在替代通路附近增加障碍；大量远处障碍只添冗余，不一定变难 |
| 支撑区数量/位置 | 1宽区域到多层区域 | 见证锚点始终有支持；优先层互斥；稀疏支撑会与回路几何耦合 |
| 柔性紧度 | 见证应力比接近0.2/0.6/0.9等 | 用精确比率分组；保留正参数与可变量立方；按需调整并记录合成物理参数 |
| 单管上下文 | 将已固定管段增加为障碍 | 贴近论文顺序子问题，来源与固定顺序应记录 |
| 联合管路数 | 1、2、4、8等 | 先造互相避让的多路见证，加跨管段分离；标记联合扩展，不能用顺序总成本作opt |
| 成本竞争 | 改长度/弯头/支撑的正有理比率 | 各组记录费用及缩放，防止目标全常数；目标上界取安全推导值 |

不要通过把同一个实例整体几何缩放就宣称获得独立难度层级。按英制/网格系数推导，若物理尺寸、D一起缩放s且K不变，整数长度立方和及GCM左侧都按s³变化；可能只是等比例复制而近似同构。只增容器空域、只变K、只改物理直径的效果不同，应分别测量约束是否紧、编译简化后是否仍含变量乘法。

若生成UNSAT组，可有意选择小容器、大管径、缺少支撑或较大正GCM系数，但这些不能由“未找到见证”直接宣称无解；需完整求解证据。主集合建议先采用有见证的SAT/优化实例，另列已验证UNSAT组。

## 9. 如何正确标记最优值与验证

论文表1（p.332）中各求解器都能把每条无GCM子问题解到最优，总费用仍不同；原因是顺序求解过程中前面某条选择了不同的局部最优路由，改变后续障碍。表2（p.333）部分求解器/精细网格还有timeout。`Nopt`是被证得最优的管路数量，不等于全厂最优证明。

独立忽略其他管路求各条最优并求和，论文用作联合路由问题的下界，前提是同一网格/同一费用/同一其他约束，并且每条均已最优。其路线可能互相碰撞，所以不能当联合可行解。K变化后，该下界数值也不能直接作新网格下界。

后续验证应包括：

- 静态检查SMT只含`Int`/`Bool`，有变量乘变量/整数立方、整数有界目标，没有混入Real、浮点求解或MIP查表版。
- 独立按原输入复算节点—段长—方向、尾部重复、六向分离、附件例外、支撑锚点、GCM所有轴分支与目标费用。
- 原源码翻译验证编译期系数和`div+1`费用一一对应；论文精确版验证正分母清除、单位转换及条件分支的等价性。
- 每个见证给`feasible_cost`，仅当求解器证明最优并验证严格更优界UNSAT时记录`optimal_cost`/`globalopt`；未知使用明确unknown，不把可行成本填进最优字段。
- 为成本缩放给`objective_scale`，明确公开模型值、格点长度费用和美元物理费用之间的转换；如果采用非统一取整，保存“新目标”而不能仅标scale。

建议第一批优先做已收集5个单管源模型的忠实NIA翻译，然后做3–10段、少障碍、正有理GCM、带可行见证的合成单管系列。联合多管可作为后续扩展。这样既有可追溯的现成非线性数据，又能得到规模、网格、支撑与柔性紧度可控的新benchmark。
