文件 prompts/00_master.txt

OMT NIA 应用实例生成器总提示词

一、你的任务

你是一名负责实现研究 benchmark 的 Codex。请建立一个 Python 项目，把四类应用转成可重复生成的 OMT(NIA) 输入，并实现独立的解检查器。请完成实际代码和可运行小样。

四类应用如下。

1. 整数持仓均值方差优化：持仓数必须为整数，目标是实际风险二次式。
2. 循环资源调度：周期和迭代编号为整数，保留恢复单次迭代跨度中的 k_i*T。
3. 最小面积排样：宽、高、位置为整数，目标为 W*H。
4. 精确 D 最优实验设计：实验重复次数为整数，最大化信息矩阵行列式。

目标不是从普通 SMT(NIA) 公式中随机挑一个变量，也不是为了出现乘法而添加与应用无关的约束。每个实例须能解释为一个完整的应用决策。

二、先读资料并界定转换

逐项读相应应用提示词中的模型和来源。reference_starter/convert_models.py 是小范围转换参考，不是完整的 GAMS 或 MiniZinc 编译器。

为每个生成 profile 明确区分：

upstream_model_instance：转换已公开的原模型及其数据。
upstream_model_generated_parameter：沿用原模型，生成新参数，例如方块数量 n。
new_application_family：根据应用数学模型自行设计数据，例如整数向量 D 最优设计、带可行调度见证的新循环调度。

另用 model_changes 列出约束或目标的修改。数据来源类型和数学等价性不能共用一个含糊的“来自论文”标签。相关论文支持应用与建模背景，不自动证明某个仓库文件就是论文代码。

保留 URL、实际下载日期、文件名、字节数、SHA256；能取得 Git commit 就一并记录。对可变 master 分支至少保存内容哈希。已知原始文件的哈希在 references/source_inventory.json。上游发生变化时给出差异，不能覆盖缓存后仍声称复现旧版本。

三、精确理论边界

主输出为 QF_NIA：所有算术未知量为 Int，逻辑未知量可以为 Bool；无量词。目标是有明确应用含义的整数多项式 cost。

有限小数按原始十进制文本解析为精确有理数，再用正整数公分母清除常数分母。可使用 Python fractions.Fraction。禁止先转 float 再 Fraction，禁止按固定小数位四舍五入。

SMT 算术只需整数常量、+、-、*、比较和 ite。幂用重复乘法或共享表达式表示。不要留下 log、exp、矩阵逆、实数强制转换、变量除法或未解释的“det”函数。生成器内部计算常数行列式可以使用精确除法；这不意味着可以把变量除法写入 SMT。

约束版 base.smt2 使用标准整数理论。优化版 opt.smt2 使用 minimize/maximize 扩展；这些优化命令不是通用标准 SMT-LIB 核心指令。求解器适配器须针对实际安装版本核验支持，不能写“所有 SMT 求解器都能直接运行优化文件”。

保留多值整数变量的乘积。0/1 选择器乘数值可用 ite 编码，但不要借此把真正的 k_i*T、W*H 或实验次数多项式替换成固定参数。可以另外提供等价线性化 profile 做对照，主 NIA profile 必须保留原结构。

这些首批应用均使用有限变量域或可推出的有限域，不用于展示无界优化。给变量加界必须能从原模型推出，或明确标成新 profile 的建模选择。

四、建议项目结构和统一命令

使用包名 nia_bench。目录建议：

nia_bench/
  cli.py
  core/                 精确数、表达式、SMT 输出、元数据
  families/             四类应用的输入解析与建模
  validators/           从应用参数独立重算约束和目标
  solvers/              可选的求解器进程或 API 适配器
configs/                smoke 和分规模生成配置
data/raw/               下载缓存，原文件保留原样
build/                  生成结果
tests/                  语义回归和微型穷举检查
README                  安装、命令、来源和结果解释

可以调整内部结构，但实现并记录下列命令含义。参数列表中的逗号表示明确的多值列表，不能悄悄当作连续区间。

python -m nia_bench fetch --family portfolio --profile minlplib --cache data/raw
python -m nia_bench fetch --family cyclic --profile minizinc --cache data/raw

python -m nia_bench generate portfolio --profile minlplib --ids smallinvDAXr1b150-165 --cache data/raw --out build
python -m nia_bench generate portfolio --profile synthetic-gram --assets 8 --seed 1 --out build
python -m nia_bench generate cyclic --profile minizinc --ids easy_1,easy_2,medium_1,hard_1 --cache data/raw --out build
python -m nia_bench generate cyclic --profile planted --real-tasks 12 --resources 2 --period 10 --extra-edges 16 --seed 1 --out build
python -m nia_bench generate packing --profile squares --n 3,4,5 --out build
python -m nia_bench generate packing --profile rectangles --items 12 --max-side 8 --seed 1 --out build
python -m nia_bench generate design --profile integer --dimension 3 --candidates 6 --runs 6 --seed 1 --encoding cauchy-binet --out build

python -m nia_bench validate build --tier witness
python -m nia_bench verify-optimum PATH_TO_ONE_CASE --timeout 30
python -m nia_bench suite --config configs/smoke.json --out build/smoke

period 是新循环调度生成时的可行见证参数，不能因此把求解模型中的周期 T 固定为该值。各应用提示词会说明其他参数的实际含义。

生成与解检查尽量只依赖标准库；使用外部 SMT 求解器、MiniZinc 或数学规划工具进行额外核验时列为可选依赖。不要要求每次生成实例都先求得全局最优解。

五、每个实例的交付格式

每个实例存放在 build/{family}/{stable_instance_id}/ 下，至少有：

data.json：应用原始参数；足以重新构建模型，不能只保存 SMT 字符串。
base.smt2：声明、整数域和全部约束，包括 cost 的定义；不含优化命令和查询命令。
opt.smt2：相同声明和约束，加唯一一个 minimize/maximize cost 和 check-sat。
metadata.json：来源、转换、单位、变量解释、目标恢复关系和结构统计。
witness.json：可行应用决策及精确目标；没有见证时明确状态，不能伪造。
validation.json：各层检查结果、方法、工具版本和未完成项。

本包 tiny_fixtures.json 是回归数据，不是新项目必须照搬的内部 schema。请为你的 schema 编写简短规范并保持版本号。

JSON 中很大的整数系数和目标值用十进制字符串，避免其他语言读取时损失精度。精确有理数使用 {"num":"整数","den":"正整数"} 并约分。小型计数、维度、下标可用 JSON 整数。明确下标从 0 还是 1 开始；SMT 变量和原应用变量的映射必须可恢复。

metadata.json 至少记录：

schema_version、family、profile、instance_id、origin、model_changes；
generator_version、seed、完整参数、源输入和输出文件 SHA256；
source_records，含论文和实际模型文件的不同角色；
decision_variables，含类型、单位、域及其来源；
objective，含 sense、SMT 符号、应用名称、单位、正缩放因子和恢复公式；
nonlinearity，含最大应用多项式次数、多值整数乘积数量、布尔选择乘积数量；
size，含应用变量数、辅助变量数、断言数、析取数、文件字节数；
feasibility_status、optimality_status、验证方法、限时及工具版本。

计数说明要一致。若用了辅助门变量，分别记录原应用多项式次数和编码后局部等式次数，不能把五次行列式电路只报成“二次原问题”。

六、可重复生成和实例质量

对每个实例使用局部随机数生成器，记录 seed 与生成算法版本。对同一版本、相同缓存和参数，两次生成的语义文件必须字节一致。时间戳放在单独的运行记录，别让它破坏实例内容哈希。

稳定排列变量、单项式、约束和 JSON 键。随机参数之外的数据变化也必须进入 ID 或哈希。失败重试需有次数上限，记录失败原因，不得无限循环。

新生成数据先构造或寻找一个可行应用决策，再独立验证；生成时的见证只能写在 witness.json，不能作为等式约束固定全部决策。

原来源数据可能不可行或参考点不可用。保留真实状态，不能因为想要“全部 SAT”而删原约束。生成失败、解析不支持、求解超时、SMT unknown、已证 UNSAT 必须分开。

发布多种规模、参数密度、种子和目标结构。原参数族相同的重复文件不算多样性。去重既看数据哈希，也报告归一化后的系数或模型指纹。

“容易”“中等”“困难”在没有计时前只是规模标签。最终难度以固定环境、求解器版本和时间限制实测。保留容易实例用于正确性验证。

七、按阶段交付

阶段 A：先做四类微型例、统一序列化、SMT 输出和独立检查器。精确核对本包给出的目标与可行解。

阶段 B：重放四个 MINLPLib 和四个 MiniZinc 数据文件、n=3..10 的方块排样，以及三个已有 D 最优整数子族小样。对照 reference_starter 的目标定义和现有验证记录，补齐缺项。

阶段 C：做新参数生成，包括 synthetic-gram 持仓、planted 循环调度、矩形排样、可控维度的整数或有理数 D 最优设计。先生成一个 smoke 集，再用配置扩充。不要一次生成大量无法检查的文件。

阶段 D：实现微型穷举或严格改进查询，给出精确最优值回归；整理来源、等价转换说明、分规模清单和复现命令。

每阶段都必须有实际可运行产物。无需写新的优化求解算法，也无需把全部大实例跑到最优。若求解器不可用，完成生成和纯 Python 检查，单列尚未执行的 SMT 检查；不得写“已通过”。

八、完成标准

我应能用明确的一条命令生成实例，再用另一条命令独立检查一个解。阅读单个实例目录就能理解它对应什么应用、原始参数是什么、数学目标是什么、来源和变换是什么。

所有等价性证明都须满足应用提示词列出的前提。完整验收按 prompts/05_validation_and_release.txt 执行。遇到现有小样与原模型冲突时，以原文件及数学语义为准，给出具体修正，不能把旧小样当成不可质疑的真值。


文件 prompts/01_portfolio.txt

整数持仓均值方差优化实例生成器提示词

一、任务和来源

请实现整数持仓风险优化的 OMT(NIA) 实例生成器。先精确转换 MINLPLib 的 Small Investor Mean-Variance Portfolio Optimization，再实现一个明确标为新构造的整数协方差数据族。

单独使用本文件时，也必须遵守：全部算术未知量为 Int；有理常数精确清分母；输出原始参数、SMT 约束版及优化版、来源元数据、可行见证和独立检查报告。不要把风险目标换成某只股票的持仓数量。

此应用的实际来源是模型库，不是已经定位到的一篇专门 OMT 论文。MINLPLib 标出的原来源为 POLIP。请按这个证据强度署名，不能补造论文题名。

代表实例：
https://www.minlplib.org/smallinvDAXr1b150-165.html

GAMS 数据和模型：
https://www.minlplib.org/gms/smallinvDAXr1b150-165.gms

AMPL 版本，可用于交叉检查变量整数性及非负域：
https://www.minlplib.org/mod/smallinvDAXr1b150-165.mod

公开持仓点：
https://www.minlplib.org/sol/smallinvDAXr1b150-165.p2.sol

目录和撤下记录：
https://www.minlplib.org/instances.html

MINLPLib 页面标注 CC BY 4.0，应保留模型库和原来源署名。精确转换以下载的模型文件文本为输入，不能从网页的浮点摘要重建系数。

二、应用决策和参数含义

x_i 是第 i 个资产持有的最小交易单位个数，x_i 为非负整数。某个原问题的最小单位可能是一股或更小交易单位；整数决策是该单位的个数，不是任意连续投资比例。不要在未取得单位说明时把所有 i_i 都写成“一整股”。

p_i 是对应单位的价格，B_min 和 B_max 是投入预算区间。原模型还有一条线性收益要求，统一记成 R(x)>=0；原文件中的系数已组合了收益要求，不能直接把它们称为未经处理的单资产收益率。

风险 Q(x) 是持仓的二次多项式。GAMS 文件用显式展开的平方项和交叉项表示。读入 a_ij*x_i*x_j 后，应只计入这个已给出的系数；不能再按对称矩阵习惯把交叉项乘 2。

三、原模型到纯整数优化的转换

代表文件有 30 个非负整数持仓变量和一个连续辅助变量 objvar。四类约束为：

e1：Q(x) - objvar <= 0。
e2：R(x) >= 0。
e3：sum_i p_i*x_i >= B_min。
e4：sum_i p_i*x_i <= B_max。

原目标为 minimize objvar。首先检查 objvar 只出现在风险上界约束和目标中，且没有额外域限制改变可取的最小值。在这一前提下，消去 objvar，改为 minimize Q(x)，保持最优持仓及应用最优值。

设 D 为 Q 的全部有理系数分母的最小公倍数，D>0。定义整数 cost=D*Q(x)，最小化 cost。应用风险值为 cost/D。

每条线性约束可独立选择自己的正公共分母 L_j，整式乘 L_j 后保留原不等号方向。约束缩放因子不必等于目标缩放因子。

不得用统一的“乘 100”代替计算。已有四个 DAX 小样目标的 D 恰好都为 2500000000，但生成器必须从输入计算。

当所有 p_i>0 且 x_i>=0 时，可推出有限界：

0 <= x_i <= floor(B_max/p_i)。

添加这些界时将其记录为由预算推导的冗余界。若价格不全为正，不得使用该推导。不要通过任意小的持仓上限截断原实例。

四、实现受控的模型解析器

实现能读本族源文件的受控解析器即可，不要求支持完整 GAMS。支持整数声明、显式数值常量、变量、加减、乘法、括号和 sqr。

十进制与科学计数法从词法 token 精确转 Fraction。禁止 eval 整个下载文件；可使用白名单 AST 或专用解析器。默认非负整数域须由原语言规则及 AMPL 文件核对。识别 .lo、.up、.fx 等域修改；初始化 .l 不是固定约束。

检查未知函数、未知变量、未处理方程、额外 objvar 用途和未支持的语法。遇到它们明确报错，不允许“忽略后仍输出成功”。

原文件中的 Model、Solve、打印限制和求解器参数等已知样板可识别后跳过，但不能执行下载文件。首批转换的是默认无外部参数注入的模型；若条件 include 实际被启用，须显式展开并记录其输入，或报告不支持，不能当作原模型没有这些附加内容。

六、新整数风险数据族的明确生成方法

profile 名为 synthetic-gram，origin 为 new_application_family。该族有金融风险优化的数学结构，不是新的真实 DAX 市场数据。

输入参数：资产数 m、风险因子数 q、价格范围、持仓见证范围、预算松弛比例、收益要求紧度、整数系数范围、seed。

可实现以下构造：

1. 用 seed 生成整数风险因子矩阵 A，形状 q*m；生成正整数 lambda。
2. 令 Sigma=A^T*A+lambda*I。因此 Sigma 严格正定，Q(x)=x^T*Sigma*x 为自然的二次风险，具有可核验的 PSD 来源。
3. 生成正整数单位价格 p_i，统一用“分”或一个明确的离散货币单位；生成整数预期收益系数 r_i，说明其为合成的同单位收益分值。
4. 生成非负整数持仓见证 x_star，至少两个资产为正且部分变量允许大于 1。
5. 计算 b_star=p^T*x_star，选取 B_min<=b_star<=B_max，例如在 b_star 周围给定相对松弛。收益阈值 R_min<=r^T*x_star，从配置的紧度计算。
6. 约束为 B_min<=p^T*x<=B_max，r^T*x>=R_min，x>=0 整数；最小化 x^T*Sigma*x。
7. 独立重算见证、预算和风险；见证不写成 x=x_star 的求解约束。

选择参数避免所有交叉项为 0、只有一个资产能买、预算只允许一个分配，或收益约束对全部可行持仓自动成立的单一退化模式。不能为了“变难”破坏 Sigma 的风险解释。

A 和 Sigma 都要保存，验证 Sigma 的构造关系。展开 x^T*Sigma*x 时对角为 Sigma_ii*x_i^2，i<j 的交叉系数为 2*Sigma_ij；这与读取已经展开的上游 GAMS 系数不同。

预算和收益阈值是新合成参数，不混入原 MINLPLib ID。默认不添加交易费用、基数限制、杠杆或其他应用扩展；若添加，单设 profile 并说明变化。

二、实例的实际含义

n_res=R：资源种类数。

四、逐项精确转换

变量域：

0<=s_i<=U，0<=k_i<=n，全部为整数。
T=s_n，既可使用别名，也可设辅助等式。

前置关系严格采用源公式。对每条 (i,j,l,delta)：

b_e <=> (s_i+l<=s_j)。
k_i+ite(b_e,0,1)<=k_j+delta。

可直接将 b_e 代入 ite，避免多余布尔变量。不能把该公式擅自替换成自己熟悉的另一种循环前置关系；即使认为形式相似，也要先证明两者在此参数范围内等价。

冗余的两两不重叠：

若存在资源 r 使 rreq[i,r]+rreq[j,r]>rcap[r]，保留
s_i+d_i<=s_j OR s_j+d_j<=s_i。

资源累计约束：

只计需求为正、持续时间大于 0 的真实任务。对于每种资源，在每个真实任务的开始时刻检查：

sum_j ite(s_j=s_i,rreq[j,r],0)<=rcap[r]。

整数开始时刻加单位持续时间意味着两个执行区间重叠当且仅当开始时刻相同，所以上式对此模型精确。若总需求已不超过容量，可如源代码跳过该资源检查。虚拟任务不消耗执行时间。

不要把此等开始时刻规则用于一般持续时间。一般半开执行区间 [s_j,s_j+d_j) 要改成 s_j<=s_i<s_j+d_j 的事件占用检查，并单设新 profile。

周期条件：

k_n=max(k_1,...,k_(n-1))。
对 i<n，s_i+d_i<=s_n。
s_1=0，k_1=0。

跨度与目标：

u_i=s_i-k_i*T，i=1..n-1，包括虚拟源，排除虚拟汇。
lo=min_i u_i，hi=max_i u_i。
C=hi-lo+1，0<=C<=U。
cost=U*T+C，0<=cost<=U*(1+U)。
minimize cost。

精确 max/min 编码：

hi>=每个 u_i，并且 OR_i(hi=u_i)。
lo<=每个 u_i，并且 OR_i(lo=u_i)。

只加单侧包络而不要求取到某个值，不能保证变量等于真正的 max/min。即使目标有时能压紧，也不要依赖未经证明的目标传播。

C 的实际取值至少为 1。因为 C<=U，权重 U 足以让 period 优先、C 次之。保留源权重，不要误写成 U+1 后还声称逐值相同；另设等价字典序 profile 可以，但要记录。

五、新实例的可行构造法

profile 为 planted，origin 为 new_application_family。以下是本提示词提出的构造，采用同一个 rcmsp 约束模型，不能标成原论文的数据生成器。

输入 q>=2 个真实任务、R>=1 类资源、见证周期 P>=2、额外边数、需求和容量范围、seed。n=q+2。CLI 的 --period P 仅控制生成时的见证，不向 SMT 添加 T=P。

按下列过程生成，无需先求全局最优：

1. 生成正资源容量和非负整数需求，每项需求不超过对应容量，每个真实任务至少使用一种资源。为真实任务分配整数相位 s_i in [0,P-1]，逐个放到各资源均有剩余容量的时隙。没有可放时隙则有限次重采样；不得无限重试或悄悄增加 P。
2. 选 cut in [1,P-1]，令真实任务 k_i=0 当 s_i<cut，否则 k_i=1。尽量保证真实任务在 cut 两侧都有样本。源任务为 s_1=0,k_1=0；汇任务为 s_n=P,k_n=1。
3. 按相位非递减顺序连接一条“源 → 所有真实任务 → 汇”的骨架链。每条链边 latency=后继相位-前驱相位，distance=0。允许同相位边的 latency=0。
4. 链上延迟非负且和为 P；每条边在见证中 b=true，k 随相位不减，因此满足源前置公式。这条骨架也保证计算出的 U 至少为 P。
5. 随机增加依赖边 (i,j,l,delta)。先选 i、j 和非负整数 l，再取
   delta=max(0,k_i-k_j+I[s_i+l>s_j])。
   可以加配置允许的非负余量，但须记录。这样该边满足精确源公式。
6. 如需有回边的族，显式生成至少一条从较晚相位任务指向较早相位任务的边，并记录正迭代距离。不要只生成没有循环依赖结构的 DAG 后统称已覆盖所有循环调度。
7. 从最终的边重新计算 U；重算 C 和 cost，并用独立检查器验证全部变量域、前置、资源、两两约束和目标。

为什么不会出现 U 太小的循环依赖问题：

骨架链延迟和为 P，新增边只增加非负延迟，所以 U>=P。cut 构造下，低相位 u_i 在 [0,cut-1]，高相位 u_i 在 [cut-P,-1]，源的 u_1=0，因此 C<=P<=U。T=P<=U，k_i 在 {0,1} 内，全部界均成立。

这里仅构造了一个 k 取 0/1 的见证；求解模型中仍是 k_i in [0,n] 的多值整数变量，不得把模型的全部 k 限定为布尔。后续若生成更大迭代层数，须重新证明 C<=U，不能直接沿用此证明。

生成时须保存 planted 的 s、k、cut、相位负载和边构造方式。所有见证赋值都不能进入主约束。该生成分布有 planted 和骨架链的结构偏差，应与公开数据分开统计，不能把“可行”当作“困难”。

排样对应切割、版图等应用背景；1x1 到 nxn 的方块族是标准合成组合实例，不是真实芯片设计或工厂测量数据。不能把生成的随机尺寸包装成工业数据。

此类适合做来源清楚、易检查的基础应用族，核心非线性主要是一个 W*H。它不能单独代表复杂的高次 NIA。某些整数尺寸的轴对齐变体存在整数坐标最优解性质，也不能笼统声称放松为实数一定改变最优面积。

三、原方块模型的精确转换

profile=squares，origin=upstream_model_generated_parameter。

输入 n>=1。方块 i 的边长为 i，i=1..n。定义：

L=sum_i i=n*(n+1)/2。
A_min=sum_i i^2=n*(n+1)*(2*n+1)/6。

变量和域：

W,H 为整数，n<=W,H<=L。
x_i,y_i 为整数，0<=x_i,y_i<=L。
area 为整数，A_min<=area<=n*L。
area=W*H。

容器内约束：

x_i+i<=W。
y_i+i<=H。

对每一对 i<j 的不重叠析取：

x_i+i<=x_j OR
x_j+j<=x_i OR
y_i+i<=y_j OR
y_j+j<=y_i。

允许边界接触，使用 <=，不能误用 <。默认无旋转，因为对象是方块。

设 cost=area，minimize cost。

源简单模型里的 diffn 和 cumulative 调用被注释，不需要实现它们的全局传播器。四选一析取已表达所需不重叠语义。

保留源模型的面积和尺寸界。初始搜索注解不属于约束；输出可注释说明，不要求模拟 MiniZinc 的搜索顺序。

四、固定尺寸矩形扩展

profile=rectangles，origin=new_application_family。这是同类排样应用的新数据与显式模型扩展，不能写成原方块源码的逐字转换。

输入每个工件的正整数尺寸 (w_i,h_i)。默认固定方向。未知量是 W,H,x_i,y_i，目标仍为 W*H。

不重叠将上节的方块边长分别替换为 w_i、h_i。设

W_min=max_i w_i，H_min=max_i h_i。
A_min=sum_i w_i*h_i。

构造一个水平条带可行见证：

W0=sum_i w_i，H0=max_i h_i。
x_i=sum_(j<i) w_j，y_i=0。
UB=W0*H0。

可用该可行解对优化空间作保优剪枝：

A_min<=area<=UB。
W_min<=W<=floor(UB/H_min)。
H_min<=H<=floor(UB/W_min)。
0<=x_i<=W_max，0<=y_i<=H_max。

这些上界排除了比已知见证更差的可行排样，保持全局最优值，不保持原来“所有任意大容器解”的集合。元数据应写 optimization_preserving_bound，不能声称所有解一一对应。

方块源模型的 n*L 上界依赖特定的 1..n 边长族，不能直接用于一般矩形。

可选的 90 度旋转要另设 rotations profile，用 Bool 和 ite 得到实际宽高。重做适用于该变体的尺寸下界，不能继续使用固定方向的 max(w_i)、max(h_i) 作为每个轴的必要下界。首批不要求此扩展。

五、新矩形数据的生成方法

输入参数包括工件数、边长上下界、seed、尺寸分布。先支持明确的整数均匀分布；后续可加大小混合、细长矩形、重复尺寸等分布，每种分别标注。

保存完整尺寸列表，单位写作 grid_unit。用水平条带提供可行见证，但不能固定求解器采用这个条带，也不能固定 W。

不要默认只生成已知完美拼接实例。若 A_min=UB 且见证达到该面积，优化已被上下界立即解决，可保留为正确性例，但应标成 exact_tiling_easy。

不要把固定宽度、只最小化高度的 strip packing 替代主模型；固定 W 后面积目标变成线性，与这里研究的目标结构不同。它可以作为单独的 LIA 对照。

不同种子可能生成同一尺寸多重集。保留工件编号映射，另外计算规范尺寸多重集指纹，避免把简单重排当成新 benchmark。

六、可手算回归例

取 n=3，即边长 1、2、3 的三个方块。

L=6，A_min=14，源面积上界为 18。

一个可行最优排样：

W=5，H=3。
方块 1：x1=3，y1=2。
方块 2：x2=3，y2=0。
方块 3：x3=0，y3=0。

面积为 15。所有边界允许接触。

精确最优性：面积至少为 14，而 W,H 是至少为 3 的整数，14 不能分解为满足该下界的两个整数维度；上述见证面积为 15。因此最优值为 15。也应运行 area<15 的 UNSAT 查询。

通用条带见证为 W=L，H=n，x_i=i*(i-1)/2，y_i=0，面积 n*L。它只证明可行，不是一般最优解。

七、独立检查器

从 data.json 读取尺寸，检查 W,H、坐标的整数性、非负性、容器内约束。对所有工件对，直接计算两个半开矩形的交集是否有正面积；不要读取 SMT 的四选一布尔结果来代替几何检查。

精确计算 W*H 并核对 cost。若允许旋转，检查方向取值和实际尺寸。人工注入一个越界、一个重叠、一个错误面积的解，检查器应分别拒绝。

可以导出 SVG 作为人工理解辅助，标上尺寸和坐标；几何检查结果以整数算术为准。无需为每个实例生成图片。

八、首批验收与规模

先重放 n=3..10，与参考小样的域和目标一致。另测 n=1、n=2 的边界情况。

新矩形 smoke 建议用 6、12、24 个工件、每种两个种子，最大边长 8 或 16。面积系数本身不需要浮点缩放。

报告工件数、尺寸分布、目标上下界、非重叠析取数 n*(n-1)/2、宽高变量域、可行见证面积。实际难度须计时后填写。

若添加 W>=H 等对称性破除，证明旋转整个排样保持当前实例语义，并记录为可关闭选项；固定方向一般矩形不自动具有这种旋转对称性。

对可行性、最优性、原模型逐值等价与新数据生成分别给出结果，不能用“Z3 读入没有报错”替代应用语义检查。

精确 D 最优实验设计实例生成器提示词

一、任务和论文来源

请实现精确 D 最优实验设计的整数或有理数系数子族，生成带自然三次、四次、五次等多项式目标的 OMT(NIA) 实例。

单独使用本文件时，全部决策为整数实验次数；输入实验向量为常量；输出参数、SMT、来源、目标缩放、见证和独立行列式检查器。不要把未知回归系数引入优化而变成含实数决策的另一个问题。

论文：
Deborah Hendrych, Mathieu Besançon, Sebastian Pokutta.
Solving the Optimal Experiment Design Problem with Mixed-Integer Convex Methods.
https://arxiv.org/abs/2312.11200

本次模型核对使用的修订文本：
https://arxiv.org/html/2312.11200v7

相关 SEA 2024 版本：
https://doi.org/10.4230/LIPIcs.SEA.2024.16

作者实现和实验代码：
https://github.com/ZIB-IOL/OptimalDesignWithBoscia

arXiv 后续修订与 SEA 版本的标题和内容可能不同，复现实验须记录具体版本。此处转换来自论文的 D 最优数学模型，不声称论文作者采用了下面的 NIA 编码，也不声称新整数向量就是论文原始实验数据。

二、应用语义和原模型

有 m 种候选实验，每种提供一个 d 维特征向量 a_i。n_i 是选择第 i 种实验的重复次数，必须为非负整数，sum_i n_i=N。可有重复次数上限 n_i<=u_i。

信息矩阵：

M(n)=sum_i n_i*a_i*a_i^T。

d 是待估参数个数，m 是候选实验种类数，N 是实际执行的总实验次数。不要把 m 与 N 混淆，也不要把 n_i 当作 0/1 选择器。

在同方差线性模型等通常条件下，信息矩阵刻画参数估计精度。D 最优选择最大信息行列式，等价于最小化 -log(det(M))；论文中归一化因子等正常数不改变最优次数分配。

三、目标等价转换的前提

当 n_i>=0 时 M 为半正定矩阵。只考虑 det(M)>0 的可行设计，此时 M 正定，-log 在正数上严格递减，因此

minimize -log(det(M)) 等价于 maximize det(M)。

不能把 log 当作 NIA 函数留下，也不能忽略正定条件。对 Gram 型半正定 M，加 det(M)>0 即足够保证正定，不需要在 SMT 中计算特征值。

候选矩阵 A 满列秩并不自动保证存在满足 N 和所有 u_i 的正定设计。生成器必须给出满足预算及次数上限的满秩见证；例如 N<d 的默认无先验问题不可能正定。

首批采用没有先验信息矩阵的模型。若引入固定先验 M0，则 M=M0+sum n_i*a_i*a_i^T，编码和次数可能变化，须另设 profile。

四、整数及有理数输入

整数 a_i：M 每个元素是 n 的整数线性式，det(M) 是总次数至多 d 的整数多项式。满秩情况下该齐次多项式的次数为 d。

有理数 a_i：设 D>0 是所有向量元素分母的公共倍数，A'=D*A 为整数。则

M'(n)=D^2*M(n)。
det(M')=D^(2*d)*det(M)。

SMT 优化 cost=det(M')，maximize cost。原 determinant=cost/D^(2*d)，记录正缩放因子；若恢复原 -logdet 值，应在外部解释为 -log(cost/D^(2*d))，不能写入 QF_NIA。

原作者浮点数据不能任意四舍五入后声称完全等价。允许两个明确模式：

1. 输入本来就是有理数或给定十进制文本，精确按该文本解释并清分母。
2. 对某浮点数据做指定分母量化，标为 rationalized_new_variant，保存原数据、量化规则和误差统计，不称为原数据的无损转换。

主生成器先做新的整数系数应用子族。复现作者大规模浮点实验是另一个明确任务，不应成为首批生成器的阻塞点。

五、推荐的精确多项式编码

第一种，矩阵行列式编码：

设 M_pq=sum_i a_ip*a_iq*n_i，为每个元素建立整数线性等式，再用排列或其他无变量除法的精确多项式表达式定义 cost=det(M)。

三阶对称矩阵 [[a,b,c],[b,d,e],[c,e,f]] 的行列式为：

a*d*f+2*b*c*e-a*e*e-d*c*c-f*b*b。

不要把矩阵元素名 d 与问题维度混用。小维度可以用排列展开；大维度不能无控制生成阶乘规模表达式。

第二种，推荐首批主 profile 使用 Cauchy Binet 多项式：

令 A 的每一行为一个候选向量。对于每个大小为 d 的候选下标集合 S，取常量子矩阵 A_S，计算 c_S=det(A_S)^2。

det(A^T*diag(n)*A)
= sum_(S, |S|=d) c_S*product_(i in S) n_i。

这一恒等式给出纯整数、齐次 d 次、多线性的目标。c_S 是输入常量，精确计算；零系数项直接省略。求解器里的 n_i 不取平方来代替这个公式。

此编码是本提示词建议的转换方法，不是引用论文的实现声明。它避免在 SMT 中计算矩阵函数，也直接暴露应用的多变量高次目标。

提供 --encoding cauchy-binet 和 --encoding determinant 两种形式，在小数据上交叉核对目标。上限按组合项数、非零项数和输出字节数控制，不能因 m 较大无提示地生成天文规模文件。

若另做共享多项式电路，记录原应用次数 d 和编码后辅助等式次数。禁止为了使用 Bareiss 等算法而把“除以前一个变量主元”直接放进 QF_NIA。Bareiss 可用于生成器内部的常量计算或解检查。

六、新整数数据的生成方法

profile=integer，origin=new_application_family。

参数：dimension=d、candidates=m、runs=N、seed、整数系数范围、可选 u_i、编码形式。基础要求 m>=d、N>=d。

最小实现：

1. 前 d 个候选向量取标准基 e_1,...,e_d，保证满列秩。
2. 剩余 m-d 个向量按局部随机数种子生成，元素在 [-c,c]。默认拒绝全零向量；是否允许重复、成比例向量须记录。
3. 无额外次数上限时 n_i in [0,N]，sum n_i=N。
4. 构造见证：前 d 个候选次数为 [N-d+1,1,...,1]，其余为 0。此时 M 为正对角矩阵，保证 det>0。
5. 若给 u_i，先保证前 d 个基向量至少各可取 1，再把剩余预算分配到有余量的候选；若容量总和不足或不能得到满秩设计，明确拒绝或有限重采样。
6. 精确重算 M、det、预算和上下限，保存次数见证，不固定求解变量。

候选向量是实验设计中的已知回归特征，并不是待估回归参数本身。目标反映在 N 次实验预算下的信息量，不是随机挑一个 n_i 来最大化。

初始应同时保留简单与较密集的目标，避免所有实例都只剩一个非零子式或某个候选完全支配。记录非零 d*d 子式数量、系数大小、重复或成比例向量数。对“难度”的判断以实测为准。

七、两个精确回归

a1=[1,0]，a2=[0,1]，a3=[1,1]。
n_i>=0 整数，sum n_i=3。

M=[[n1+n3,n3],[n3,n2+n3]]。

八、独立检查器

读取 n_i，检查整数性、非负性、总预算和上限。直接用整数或 Fraction 形成 M，用精确 Bareiss、分数高斯消元或独立等价算法求 det。检查 det>0，核对 cost 和缩放。

OMT NIA 生成器验证与交付提示词

一、任务

请为四类生成器实现有实际语义的验收流程。生成一个能解析的 SMT 文件只是第一步，还要检查它是否表达原应用、一个解是否可行、目标恢复是否正确，以及何时可以说已经求到最优。

二、第一层是输入和理论检查

核对应用参数范围、数组长度、下标、单位、源文件哈希。拒绝不支持的语法，不默默丢约束。

用 SMT 解析器或求解器前端解析每个输出。检查所有算术变量为 Int，无 Real、to_real、非允许算术函数、量词、变量除法或未解释的矩阵函数。不要仅凭 set-logic QF_NIA 这一行认定理论正确。

优化文件应只有一个应用目标，sense 正确。确认 base.smt2 与 opt.smt2 的声明、约束完全一致，优化版仅增加优化指令和查询。读取失败、进程退出错误、unsupported 不能记作 UNSAT。

结构统计区分应用变量与辅助变量，展开别名后分析次数；把纯常数或单值域退化例标出来。保留这些例作为边界测试，但不靠它们充当复杂 NIA benchmark。

三、第二层是独立应用解检查

持仓：从原有理数方程重算预算、收益和风险，核对风险=cost/D；读取展开式时不重复交叉项。

循环调度：从 s,k 和 prec 重算每条前置公式、每个时隙资源负载、周期域、kn=max(k)、跨度 max-min+1 及 U*T+C。覆盖非零 k，不仅测试全零迭代编号。

排样：直接检查整数矩形的容器边界和成对几何交叠，面积按 W*H 重算。

D 最优：直接构造信息矩阵并用精确线性代数重算行列式，核对预算、次数上限、正定和常数缩放，不能只复用生成器的目标系数表。

新生成实例必须有已检查的见证。上游原实例没有参考见证时，可用 SAT 求解寻找并独立检查；未找到前保留 not_checked 或 unknown，不能把“没有见证”写成已证不可行。

检查器必须拒绝错误解。至少构造：超预算或错误风险、资源冲突或错误跨度、几何重叠或错误面积、次数和不为 N 或错误行列式。不要仅测试生成器给出的正确解。

四、第三层是编码等价的微型检查

使用本包 references/tiny_fixtures.json 作为明确参数，不能从求解器返回结果反推预期值。

持仓微型例：完整枚举有界 x。可行点为 (1,1)、(0,2)、(3,0)，整数目标分别为 9、16、27。

循环调度微型 A：对小域 s、k 完整枚举或逐个比较应用检查器与 SMT；精确最优值 8。先利用源、汇、资源条件减少无意义枚举，再与 SMT 结果核对，不能改变原域。微型 B 检查同一相位下 cost=23 和 24 的两个见证。

排样：核对 n=3 的 area=15 见证与更小面积不存在。加入一个恰好接触边界的正例，防止 <= 被误写为 <。

D 最优：二维例枚举 10 个分配，最大值 3；有理数缩放后原值为 3/16。三维例枚举 462 个分配，最大值 1152，核对最优次数向量固定到 SMT 后确有该值。

对小随机输入比较两个独立数学实现：

持仓原 Fraction 方程与清分母整数方程。
单位时长 cumulative 的时间占用与相同时刻求和编码。
排样几何交叠与四选一条件。
D 最优矩阵行列式与 Cauchy Binet 多项式。

这些是会捕捉语义错误的检查。不要把“每个生成函数都返回非空字符串”当作核心测试。

五、第四层是精确最优性核验

若最小化目标的候选可行值为 v，运行独立检查后，再对同一 base 模型加入 cost<v 查询。

若最大化，则加入 cost>v。

只有严格改进查询明确返回 UNSAT，或已完整枚举全部有界可行决策并比较精确目标，才可登记对应方法的最优性结果。

需要分别记录：

feasible_only：有经过应用检查的可行点。
optimal_exhaustive：完整、精确的有限枚举已完成。
optimal_solver_checked：可行点加严格改进 UNSAT；记录求解器和版本。
optimal_proof_verified：另有实际输出并经验证的证明对象时才使用。
unknown 或 timeout：没有完成判定，保留已有可行值。
unsat_solver_checked：原约束被求解器判为 UNSAT，记录方法。

solver_checked 不自动等于有形式化可重放的证明对象。不要把求解器打印“optimal”但无法检查的数值目标直接升级为更强状态。

Z3 Optimize、OptiMathSAT 等适配器按实际版本测试。其他支持 QF_NIA SAT 的求解器可通过严格改进查询参与小例验证；这不表示它们原生支持优化命令。不要把尚未测试的软件支持写进结果。

可选参考优化器可反复查询 base+cost<incumbent 或 cost>incumbent。每轮都精确提取并检查应用解；UNKNOWN 时停止并保存当前界。不要把 UNKNOWN 当成最优终止，也不要做没有实际范围保证的二分。

六、确定性与来源检查

相同输入、seed 和生成器版本重复生成两次，比较 data.json、SMT 和语义元数据哈希。随机过程使用局部 RNG，记录版本。运行时间等非确定项放独立报告。

数据缓存下载后核对 SHA256，保留下载失败与内容变化。元数据写明上游原实例、新参数或新应用子族。源模型转换的双向可行性与目标对应要有逐项说明；保优剪枝则说明它只保持最优值和最优解，而不保持全部可行解。

禁止把本提示词提出的 planted 构造、Cauchy Binet 编码或整数化新数据归给原论文作者。

四、后续引用和新增应用的准入条件

对每个新增候选，先回答：

原应用本来优化什么，目标是否确实有业务或工程含义？
哪些未知量必须为整数，为什么？
非线性在哪里，是多值整数乘积还是仅有布尔选择？
原模型是否还含不能消去的真实连续未知量？
转换保持全部解、仅保持最优解，还是改变了数据或模型？
能否取得精确输入、实例生成规则和独立检查方法？

没有原工业数据时，可以生成明确标注的新应用数据族；不能把“公式看起来像”写成已复现实例。与其给每个候选硬凑生成器，先把四类已有明确规格的主应用做对。
