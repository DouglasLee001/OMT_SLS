# OMT(NIA) 待实现 idea

## 从大目标可行解尝试证明目标无界

### 整体思路

先用现有局部搜索找到一个目标值很大的、经过精确校验的可行解。最大化时可用
`obj >= 1000000`，最小化时用 `obj <= -1000000` 作为尝试证明无界的启动条件。
这个有限阈值只是启发式触发条件；达到任何有限数，包括 `2^127-1`，都不是无界证明。

基于这组解，选取一个能保证完整原公式成立的合取分支。对于 CNF，每个硬子句至少
选择一个当前为真的文字；必须保留负文字。比如 `(A or B) and (not C or D)` 可以
选择 `A and not C`，前提是这两个文字在基点都成立。原公式本来为合取时全部保留。
布尔门和 ITE 的定义也是硬子句，不能越过这些定义任意删约束。

### 第一阶段：固定部分变量，调用 Z3 查询 LIA 无界方向

本次实现这一阶段，使用程序已经链接的 Z3 C++ API。

1. 从已验证的大目标模型取整数基点 `m`，固定所有布尔值。
2. 选取覆盖全部硬子句的真文字。负等式 `p != 0` 按基点符号选择 `p >= 1`
   或 `p <= -1`；负不等式 `not (p <= 0)` 转为整数约束 `p >= 1`。
3. 尝试几种变量固定方案，把固定变量代入当前模型值。所有保留约束和目标必须
   严格变成线性多项式；仍非线性的项不能删除。代入后的零项和同类项须精确处理。
4. 对得到的线性合取 `A*x >= b, E*x = e`，最大化 `c*x` 时调用 Z3 求整数方向：
   `A*d >= 0, E*d = 0, c*d >= 1`。最小化则改成 `c*d <= -1`。
   固定变量和布尔变量的方向必须为零。
5. 用任意精度整数重新检查基点、文字覆盖、线性化、方向和目标斜率。全部通过后，
   `x(t) = m + t*d` 对每个整数 `t >= 0` 可行，并且目标沿优化方向无限增长。
6. 保存证书和证明完成时间，报告 `is_unbounded=true`，提前结束此实例。

检测默认关闭，以 `--prove-unbounded` 启用；触发阈值通过
`--unbounded-threshold=M` 调整，默认 `1000000`。每实例先进行一次有预算的检测，
内部尝试多个固定方案，以 `min(5 秒, 原生时间限的 5%)` 为本地调度预算，计入原时间限。
检测在预算检查点退出，实际耗时包含不可抢占的整数运算、Z3 构析和调度延迟；
是否接纳证明仍严格受整个实例的截止时间约束。
失败、超时和 `unknown` 都只表示未找到证明，继续原优化。证明模式会禁用历史
strict-win 目标早停，以免在阈值之前退出；外部已证最优值的匹配早停仍保留。

有限最好值仍单独记录，不能把它改成某个“无穷大整数”，也不能把无界标成找到
有限最优值。保存的方向可以超出 128 位；证明计算使用精确整数，不受搜索存储界限制。

### 后续阶段：用局部搜索寻找参数表达式（本次不实现）

直接搜索整数系数 `d_i`，令每个变量 `x_i(t) = m_i + d_i*t`。
`d_i = 0` 就是固定该变量；多个非零方向允许耦合变量一起变化，覆盖固定变量
化 LIA 方法可能错过的射线。

把表达式代入原合取：等式的多项式系数必须全部为零；不等式要证明在某个可计算
整数阈值 `T` 之后始终成立；目标多项式必须非恒定，并向优化方向发散。局部搜索
可以使用等式系数残差、违反的不等式符号及目标不增长作为评分，并用联合移动、
重启、最近可行解的差分等产生候选。有限个参数值的抽样只能筛候选，不能充当证明。

例如 `x >= 1 and x*y = x*x`，最大化 `x`，从 `m=(N,N)` 出发：
`x=N+a*t, y=N+b*t`，等式变为
`N*(b-a)*t + a*(b-a)*t*t = 0`。找到 `a=b=1` 就得到可验证的无界射线。

仿射模板失败后，可以扩大为 `x_i(t)=a_i*t*t+b_i*t+c_i` 等多项式模板。
例如 `y=x*x` 的增长需要曲线。即使扩大模板也不完备；找不到表达式不能推断有界。

后续还可尝试：更换合取分支、从新的可行基点重试、传播等式减少待搜索系数，
以及为更多证书类型增加独立校验。搜索和证明验算始终分开。
