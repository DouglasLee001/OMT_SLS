## 设计选择

1. 采用独立的冲突指导精确邻域：当前可行赋值作为可撤销的坐标等式 assumptions，严格改善目标作为查询的硬约束。Z3 的 UNSAT core 指出哪些坐标不能同时保持，逐步释放这些坐标；SAT 完整模型通过现有 GMP 校验后送回 SLS。释放坐标同时作为 SLS 的软变量优先级。这使同一份交互信息同时指导双方搜索。
2. 单纯增加 Z3 证明预算仅是调度，不作为本次深度交互；保留作基线。
3. 暂不重用 user propagator：旧原型存在错误有限最优反例，且注册回调会改变后端。initial-value API 在默认部分 tactic 上不实际消费，不能把调用成功当作已生效。

邻域使用完整 native CNF、精确整数多项式和原目标方向，变量全部使用新鲜声明；映射按 native 索引，不依赖预处理消去后的原名猜测。只接受完整且精确验证的改进模型。邻域 UNSAT 只用于释放坐标；只有现有独立的原 SMT2 严格改善查询可证明 A2。不会把局部限制下的 UNSAT 当成全局证明。

## 审查后的第二个通用机制：凸二次外逼近

审查确认稠密目标若释放全部 support 会失去邻域限制；第一机制现改为仅释放一个目标坐标，由真实 core 扩大，并对父端校验/发布共享 slice deadline。

另外独立实现可关闭的 `--convex-exchange`，与 core 分别消融。只在**原 source AST** 可证明满足“所有硬约束是线性整数/布尔公式，归一化最小化目标是凸二次”时适用；不能按应用类别匹配。若唯一目标是一个变量，允许消去其唯一无自引用的直接定义等式，代入所有其余硬约束和目标。这是明确的等价投影，不用 native UNSAT 代替 source 证明。

令 g(x)=c+bᵀx+½xᵀHx；最大化用 g=-f。以 GMP 有理 LDL 验证 H 半正定，零主元要求其剩余行也零，负主元/高阶/非线性 hard/资源不足都回退。SLS 赋值提供切线点 a（缺失原变量取0只影响提示质量），全局有效切平面为 L_a(x)=g(a)+∇g(a)ᵀ(x-a)≤g(x)。任何整数严格改善 g<B 必满足 L_a≤B-1。

Z3 QF_LIA 在完整线性硬公式与切平面上返回整数模型。真实多项式用 GMP 评价：若改善，恢复完整 source model 再走现有 source/native 精确桥回灌 SLS；若未改善，加入该点切平面。外逼近 UNSAT 在原公式与精确 PSD 认证下是有效全局最优证明。它是新证明通路，必须附 source 哈希、原目标、PSD/切线和线性查询等可独立复验数据，且新增A2要独立重放。不能为了候选可导入而加signed128变量界；超范围模型可产生 GMP 切线但不能截断送SLS。

先完成独立原式/PSD/切线回归，再接入现有 proof worker，保持其暂停/恢复及全局时限。core-only 与 convex-only 分别测试，禁止把二者收益混说；最终选择需过完整验收门槛。
