# 方法：可行见证驱动的非线性整数优化

*内部方法讨论稿。本文描述当前实现中的算法机制，用于作者讨论、推敲与重写，不作为可直接投稿的正文。*

我们考虑单目标 OMT(NIA) 问题。为统一叙述，以下讨论最小化；最大化通过目标取负对偶处理。原问题记为 \((F_s,f_s)\)，经过目标保持的预处理后，搜索问题记为 \((F,f)\)。其中 \(F=\bigwedge_j C_j\) 是整数多项式文字与布尔文字组成的 CNF。当前最好可行赋值为 \(a\)，目标值为 \(b=f(a)\)。严格改善问题记为 \(Q_b=F\land f<b\)，对应的原式查询为 \(Q_b^s=F_s\land f_s<b\)。

若前端已确定硬约束不可满足，则直接报告不可行。以下伪代码展开其余情况下的优化主流程；返回的赋值 \(a\) 是搜索表示中的见证，不等同于已经恢复全部原式变量的模型。

## 算法 1：整体搜索与认证框架

```text
输入：原约束 Fs，整数目标 fs，总截止时间 D
输出：有限最优值及 native 见证、无界证书、未认证的最好见证，或未找到见证

 1  (F, f) ← TargetPreservingImport(Fs, fs)
 2  a ← ⊥; b ← +∞
 3  初始化搜索状态 σ、邻域状态 η、证明状态 Π 和变量优先级 H
 4  while 当前时间 < D do
 5      if a = ⊥ then
 6          e ← FeasibilityTurn(Fs, fs, F, f, σ, D)
 7      else
 8          (kind, τ) ← Schedule(b, 搜索与证明历史, D)
 9          if kind = SEARCH then
10              e ← CoupledImprove(F, f, a, b, σ, H, τ)              [C1]
11          else if kind = CORE then
12              e ← CoreNeighborhood(F, f, a, b, η, τ)              [C2]
13          else if kind = RAY then
14              e ← WitnessRay(F, f, a, b, τ)                       [C3]
15          else
16              e ← SourceStrictCheck(Fs, fs, b, a, Π, τ)
17      if 当前时间 ≥ D then break
18      De ← e 的适用截止（缺省为 D）；H ← H ∪ e 中的核心变量
19      if e 含严格改善原式查询在当前 b 的 SAT 证据 then
20          记录此界已被反驳；b 改变前不再寻求同界 UNSAT
21      if e 含候选赋值 c then
22          if ExactAccept(F, f, c, b, min(D, De)) then
23              a ← c; b ← f(c)
24              更新搜索起点，清理旧界邻域与证明状态，并令 H ← ∅
25      else if e = OptimalAt(β) 且 β = b 且当前时间 < min(D, De) then
26          return (OPTIMAL, a, b)
27      else if e = VerifiedRay(R) 且当前时间 < min(D, De) then
28          return (UNBOUNDED, R)
29      更新调度历史；保留可续传的搜索状态
30  if a ≠ ⊥ then return (FEASIBLE, a, b)
31  return NO_WITNESS
```

算法以一个独立保存、经过精确检查的可行见证连接三个贡献：C1 构造约束耦合的改善动作；C2 利用锚点冲突扩展改善邻域，并将核心变量反馈给搜索；C3 从可行见证构造永久改善的整数射线。`SourceStrictCheck` 提供有限最优性检查和原式 SAT 模型交换，是整体框架的认证接口。

这四类工作由条件调度器交替安排，不是在每轮中依次全部执行。`FeasibilityTurn` 包含渐进式初始化、可恢复的 NIA 局部搜索和未获得初解时的原式可行性救援。所有过程共享截止时间 \(D\)；一次子过程的时间片耗尽，只表示该过程暂未返回可用结论。原式 SAT 的记录独立于候选接纳，因此即使模型无法回灌或被接纳检查拒绝，也不会反复对同一旧界寻求 UNSAT。

算法区分三类状态。\(\sigma\) 是探索状态，允许暂时违反约束；\((a,b)\) 是已校验的最好可行见证；\(\eta\) 和 \(\Pi\) 分别保存特定目标界下的邻域与证明进度。只有第 22 行的精确接纳可以改变 \((a,b)\)，因此已报告目标值单调改善。新目标界会使旧界相关状态和核心优先级失效，但不要求丢弃所有可复用搜索信息。

`ExactAccept` 从候选赋值独立重算完整 \(F\) 与目标，要求严格改善，并在适用截止时间内完成接纳和模型发布。结果 \(e\) 附带适用截止 \(D_e\)：核心邻域和证明 burst 的候选重验也计入相应时间片；没有额外接纳期限的普通搜索结果取 \(D_e=D\)。因此，子过程按时返回并不意味着父过程可以无限延后接纳。

后续可靠性论证以预处理保持可实现目标值集合为前提：

\[
\{f_s(m)\mid F_s(m)\}
=\{f(x)\mid F(x)\}.
\tag{1}
\]

普通 SLS 候选的精确检查针对 \(F\) 及 \(f\)，并不表示已经恢复全部原式变量。原式 SAT 模型通过另一方向的补全过程映射到搜索表示。式（1）说明两个表示间应保持的语义关系，不是当前运行时对导入等价性另做的一份独立证明。

## 1. 约束耦合的目标改善搜索（C1）

### 1.1 目标改善与可行性恢复

在整数非线性可行域中，一个目标相关坐标的改变，可能立即破坏与其他坐标之间的等式或乘积关系。因此，我们将目标探测与关联变量的修复组成一个联合动作。搜索维护探索赋值 \(x\)，而不是强制每一步都停留在最好赋值 \(a\)。可行区域中的普通动作要求保持硬约束并改善目标；暂时不可行的探索状态则以恢复约束为主要任务，同时保留已经取得的严格改善方向。

候选先按加权未满足子句代价比较，再按修复距离和目标值比较。对没有优于 \(b\) 的状态，附加虚拟严格改善惩罚，使搜索不会反复返回已经找到的目标水平。与虚拟惩罚相配合，私有修复问题还可以显式加入

\[
f(x)-b+1\le0,
\tag{2}
\]

将寻找更好目标转化为一次可行性搜索。因为目标为整数，式（2）与 \(f(x)<b\) 等价。这个副本保留全部硬约束；它的失败不能证明 \(Q_b\) 不可满足。

### 1.2 由依赖关系扩展单坐标动作

设一个探测动作要求修改坐标集 \(U\)。我们保持这些请求坐标不被投影覆盖，再利用受影响约束求解其他可恢复坐标。对于含一次可解变量的等式，只有整数解存在且满足搜索界时才执行代数修复；对于可识别的常量条件定义，根据守卫真值同步更新输出。投影采用有限轮处理，未能修复的部分由后续搜索继续承担。

例如，在约束 \(x+y=4\) 下最小化 \(x^2+y^2\)，从 \((0,4)\) 单独改变任一坐标都会违反等式；联合动作 \((0,4)\to(1,3)\) 则保持可行并将目标从 16 降到 10。这个说明性例子体现了联合动作的作用，不代表一次实验观测。

对于单坐标动作不能跨越的其他结构，候选生成器还提供联合非零因子修改、目标前沿探测、差分约束联动和析取见证重选。差分修复以目标 probe 为固定要求，寻找其余坐标的线性见证；析取版本在负环阻碍当前见证时，尝试替代的文字选择。所有这些过程只产生候选，完整约束检查决定候选能否成为新见证。

### 1.3 因子覆盖与线性化修复

直接代数投影并不适用于所有非线性关系。我们进一步选择一组固定因子，使剩余变量可以在严格改善条件下联合调整。设参与硬约束和目标的单项式为

\[
m(x)=\prod_i x_i^{e_i}.
\]

固定坐标集 \(Z\) 的一个充分条件是

\[
\forall m,\qquad \sum_{i\notin Z}e_i\le1.
\tag{3}
\]

给定 \(Z\) 上的整数试点 \(v\)，代入后每个单项式都至多含一个一次自由变量，因而完整问题

\[
F[x_Z:=v]\land f[x_Z:=v]<b
\tag{4}
\]

成为 LIA。二分双线性因子图可以通过颜色类产生覆盖；更一般的多项式结构则选择满足式（3）的固定集。试点既包含当前赋值附近的值，也包含小域组合、0 和较远的临界点。

式（4）是固定坐标后的精确限制问题，不是原问题的过近似。自写线性局部搜索器在这一问题上运行，允许其余坐标共同修复。返回值补齐固定坐标后，还要回到完整非线性 \(F\) 与 \(f\) 精确检查。有限试点搜索失败或线性后端 UNKNOWN，均不能证明原问题最优。

**命题 1（覆盖线性化）。** 若 \(Z\) 对硬约束和目标中的每个单项式都满足式（3），则给定任意整数 \(v\) 后，式（4）的算术原子与目标均为仿射表达式。式（4）的满足赋值补上 \(x_Z=v\) 后满足原 \(F\) 且目标小于 \(b\)。

**论证。** 固定变量的整数幂只贡献常数系数。每项剩余总次数至多为 1，因此代入后的多项式都是仿射的。代入保留原 CNF 的布尔连接与全部原子，补回固定值即可得到原问题的满足赋值。

### 算法 2：联合改善搜索的一段工作

```text
CoupledImprove(F, f, a, b, σ, H, τ)
 1  恢复探索状态 σ；以 a 保留独立的可行参照
 2  while 本片预算尚未耗尽 do
 3      若 σ 可行，优先选择目标相关坐标；否则选择冲突子句相关坐标
 4      按 H 调整候选坐标的扫描顺序
 5      生成临界点与目标 probe，并对关联定义执行有限轮投影
 6      按适用条件加入联合因子、差分联动和前沿候选
 7      按可行性、修复代价与目标排序，执行选中的动作
 8      若得到可行且严格改善的赋值 c，则返回 Candidate(c)
 9      若达到修复时机，则续搜严格界副本或覆盖线性化问题
10      若修复得到完整可行改善候选 c，则返回 Candidate(c)
11      若停滞，则尝试中性移动、目标扰动或重启修复
12  保留 σ 及可续传的修复状态，返回 NoConclusion
```

中性移动要求目标与可行性保持不变，并降低固定的约束压力；扰动则可以暂时离开可行域，但不能覆盖独立保存的 \(a\)。一次改善接纳后，还可沿未标为定义变量的整数坐标联合变化进行倍增外推，每个点重新投影和检查。有限次外推不是永久可行方向的证明。

本节的方法针对 SLS 如何产生更有希望的改善候选。下一节仍以改进搜索为目标，但引入 SMT 提供的邻域冲突信息。

## 2. 冲突核心驱动的邻域扩展与搜索反馈（C2）

### 2.1 锚定严格改善邻域

一个小邻域可以降低求解难度，却也可能把更优解排除在外。为识别哪些固定条件阻碍改善，我们在当前见证 \(a\) 附近建立可撤销锚点

\[
\kappa_i:\ x_i=a_i.
\]

设当前仍被锚定的坐标集合为 \(A\)，检查

\[
\Psi_{b,A}=F\land f<b\land\bigwedge_{i\in A}\kappa_i.
\tag{5}
\]

完整 \(F\) 和严格目标界是查询的固定部分，坐标锚点通过 assumptions 传入。初始释放定义性计算坐标及一个目标相关坐标，其他坐标尽量保持当前值。该问题可以限制整数与布尔坐标，但不删减原 CNF。

### 2.2 利用 core 解释需要放松的固定条件

若式（5）UNSAT，求解器返回一组锚点核心 \(K\subseteq A\)，满足

\[
F\land f<b\land\bigwedge_{i\in K}\kappa_i\quad\text{不可满足}.
\tag{6}
\]

因此，若存在严格改善赋值，它不可能保留 \(K\) 中的全部坐标值。算法从非空 \(K\) 中释放一个坐标，并在后续时间片检查扩大的邻域。我们不要求 core 最小，也不认为其中某个指定坐标必然需要改变。

**命题 2（核心指导的释放）。** 设式（6）成立。对任意满足 \(F\land f<b\) 的赋值 \(c\)，存在 \(i\in K\) 使 \(c_i\ne a_i\)。

**论证。** 若对所有 \(i\in K\) 都有 \(c_i=a_i\)，则 \(c\) 同时满足式（6）的全部合取项，与其不可满足性矛盾。

将 core 涉及的变量加入优先级集合 \(H\)，还能影响后续 SLS 的扫描顺序。由此，同一份冲突信息既改变 SMT 邻域的范围，也改变局部搜索的候选选择。\(H\) 只是软优先级，不是新硬约束。

### 算法 3：核心引导邻域的跨片演化

```text
CoreNeighborhood(F, f, a, b, η, τ)
 1  若 η 不属于当前 b，则建立 Qb = F ∧ (f < b) 并初始化锚点集 A
 2  若 η 已结束，则返回 NoConclusion
 3  在本片预算内续做查询构建或尚未完成的结果处理
 4  若已可查询，则至多执行一次 Check(Qb, assumptions = {κi : i ∈ A})
 5  若回答 SAT，则提取并精确检查完整赋值 c
 6      若 c 可行且 f(c) < b，则返回 Candidate(c)
 7  若回答 UNSAT，则提取锚点核心 K，并把 K 返回为软优先级
 8      若 K 非空，则从 K 释放一个坐标，保留 η 供下片继续
 9      否则结束当前邻域，不通过此接口报告全局最优
10  若真实查询回答 UNKNOWN，则结束当前 b 的邻域尝试
11  若本片仅在构建或结果处理时耗尽，则保留 η 以便恢复
12  返回已获得的优先级与 NoConclusion
```

一段邻域搜索可以跨多个时间片；新的 \(b\) 会使旧邻域失效。当前实现对真实 UNKNOWN 不继续随机释放锚点，因为没有新的 core 支持下一次释放。即使空 core 表明 native 严格改善问题不可满足，当前接口也只结束邻域；有限最优结论统一由下一节的原式证明通道确认。

本节使用 SMT core，因此属于以增强 SLS 搜索为目的的信息交互机制，不能归类为完全独立于 SMT 的纯 SLS 算法。它不要求共享完整学习子句、传播轨迹或 CDCL(T) 冲突分析状态。

## 3. 可行见证驱动的混合认证（C3）

### 3.1 原式严格改善检查与模型交换

有限最优性通过原式查询 \(Q_b^s\) 检查。若 \(Q_b^s\) UNSAT，则不存在目标小于 \(b\) 的原式赋值；结合当前可行目标值及式（1），可以确认有限最优。若 SAT，则从原式模型提取目标值，检查严格改善，再为搜索表示补齐辅助变量。只有补全成功且精确检查通过，才返回可接纳候选；补全超时或坐标超出当前搜索表示范围等情况，只会导致候选不可用。

SAT 模型补全失败不会改变原式 SAT 的结论。在 \(b\) 不变时，再次检查同一查询不可能获得正确的 UNSAT 证明，因此本文采用的可续传证明配置暂停该界的最优性尝试，把时间返回搜索。一个新的可行目标值会建立新的严格改善问题。

原式检查可以使用适用的守卫多项式放松、凸外近似、有限覆盖或 Z3 原式策略。受限问题的 SAT 只有在确实给出完整可行赋值时才用于改善；必要条件放松的 UNSAT 只有在变换有效时才用于排除原式改善。局部固定下的 UNSAT 与实数放松的 SAT 都不具备这样的对称转移关系。

证明状态绑定当前目标界。相同 \(b\) 下可以暂停和恢复已有证明进度；\(b\) 改变时重建。未获得结论时延长后续证明片，搜索再次改善时缩短证明片，并在证明之间留出搜索窗口。这些调度不改变 \(Q_b^s\) 的逻辑含义，也不提供额外单例预算。

一个连续证明窗口可以跨越多个目标界：在窗口内得到并接纳 SAT 改善后，可以立即查询新的界，但只继承这个窗口的剩余时间。更新 \(b\) 不会延长该窗口的总期限。

### 3.2 从当前模型选择可线性化的文字见证

严格改善可以反复产生有限目标值，但有限个见证不能证明无界。我们利用一个可行赋值 \(a\)，寻找一条对全部非负整数参数永久可行的改善射线。

从每个子句 \(C_j\) 中选取一个在 \(a\) 下为真的文字 \(\ell_j\)，记去重后的集合为 \(W\)。于是

\[
a\models\bigwedge_{\ell\in W}\ell,
\qquad
\bigwedge_{\ell\in W}\ell\ \Longrightarrow\ F.
\tag{7}
\]

选择偏向较易处理的布尔或线性文字，但见证必须覆盖全部子句。接着选择固定因子集 \(Z\)，将 \(x_Z\) 保持在 \(a_Z\)，使 \(W\) 中的算术多项式和目标在代入后均为仿射。这里是精确代入后得到仿射式，不能用某点的局部泰勒近似替代。

算法尝试有限个固定集，并优先探索仍保留目标改善自由度的选择。它只需找到一条满足条件的射线；某个固定集不成功，不意味着原式有界。

### 3.3 用整数线性约束合成永久改善方向

引入整数方向 \(d\)，令

\[
x(t)=a+t d,\qquad t\in\mathbb Z_{\ge0}.
\tag{8}
\]

式（8）只对整数坐标做加法，布尔值始终保持基点真值不变；等价地，将布尔方向记为 0。固定整数坐标满足 \(d_i=0\)（\(i\in Z\)）。对每个代入后为仿射的算术多项式 \(p\)，沿该方向有

\[
p(a+td)=p(a)+t\,s_p(d),
\tag{9}
\]

其中 \(s_p(d)\) 是关于 \(d\) 的整数线性表达式。方向约束按见证文字的极性构造：

| 在基点为真的见证 | 保持其对所有 \(t\ge0\) 为真的方向条件 |
| --- | --- |
| \(p=0\) | \(s_p(d)=0\) |
| \(p\le0\) | \(s_p(d)\le0\) |
| \(\neg(p\le0)\)，即 \(p\ge1\) | \(s_p(d)\ge0\) |
| \(p\ne0\) 且 \(p(a)\ge1\) | \(s_p(d)\ge0\) |
| \(p\ne0\) 且 \(p(a)\le-1\) | \(s_p(d)\le0\) |

最小化还要求

\[
s_f(d)\le-1.
\tag{10}
\]

这些条件组成 QF_LIA 问题。SAT 给出候选方向；UNSAT 或 UNKNOWN 只结束当前固定方式的尝试。方向提取后，用精确整数运算重新核对基点可行性、子句覆盖、代入后的仿射性、所有斜率条件及目标严格改善。

### 算法 4：由可行见证合成无界证书

```text
WitnessRay(F, f, a, b, τ)
 1  W ← 为每个子句选择一个在 a 下为真的文字，并去重
 2  for 每个可在剩余预算内尝试的固定集 Z do
 3      将 xZ 固定为 aZ
 4      若 W 或 f 的残余多项式仍非仿射，则继续下一固定集
 5      L ← 固定坐标/布尔方向为 0 的约束
 6      L ← L ∧ W 的极性斜率条件 ∧ (sf(d) ≤ -1)
 7      ans ← LIA.Check(L, 剩余本片预算)
 8      if ans = SAT then
 9          R ← (a, d, Z, W)
10          if ExactRayCheck(F, f, R) then return VerifiedRay(R)
11  return NoConclusion
```

**命题 3（射线证书的可靠性）。** 假设 \(a\models F\)、\(b=f(a)\)，\(W\) 满足式（7），固定 \(x_Z=a_Z\) 后所选算术多项式及目标均为仿射。若整数方向 \(d\) 对所有固定坐标满足 \(d_i=0\)，全部布尔值沿射线不变，且 \(d\) 满足上述极性条件及式（10），则对所有整数 \(t\ge0\)，\(a+td\models F\)，且 \(f(a+td)\to-\infty\)。

**论证。** 固定坐标及布尔真值沿射线不变。每个所选算术文字由其基点真值与式（9）的斜率条件可知，在全部 \(t\ge0\) 上保持为真；特别是负等式沿基点所在真分支不跨越零。根据式（7），每个子句始终至少有一个真文字，因此整式保持可行。目标满足 \(f(a+td)=b+t\,s_f(d)\)，由式（10）趋向负无穷。

式（1）进一步将这一无界目标值集合对应到原式。它不要求当前实现为每个 \(t\) 显式输出一份恢复了所有原式变量的模型。

例如，约束 \(x\ge0,y\ge0,z=xy\)，目标为最小化 \(-z\)。对任意正整数 \(k\)，可行基点 \((k,1,k)\) 与方向 \((0,1,k)\) 给出 \(x(t)=k,y(t)=1+t,z(t)=k(1+t)\)，因此目标为 \(-k(1+t)\)。固定因子 \(x=k\) 后，关系与目标沿该方向均为仿射。这是证书构造的说明性例子，不是以大数代替无界证明。

### 3.4 适用范围与结论边界

有限大目标仅用于触发和辅助探索；当前实现达到有利方向的阈值后，至多启动一次有界预算的射线构造。可靠结论来自命题 3 的条件核验，不来自目标值的绝对大小。该证书覆盖在选定文字见证和部分因子固定后可仿射化的整数射线，不覆盖所有无界 NIA 问题，也不把构造失败解释为有界。

算法的三个公开结论相互分离：精确可行候选提供当前目标值；完整原式严格改善无解提供有限最优；核验成功的射线提供无界性。搜索失败、局部邻域 UNSAT、固定集试探失败和预算耗尽都不会升级成全局认证。因此，算法提供上述条件下的结论可靠性，不声称对一般 OMT(NIA) 完备。
